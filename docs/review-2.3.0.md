# 2.3.0 작업 완료 기록

검토·수정일: 2026-10-08. Claude가 남긴 2.2.2 기반 미완성 패치에서 이어서 작업했습니다.

## 동작

- 목록 행 범위 드래그, 갤러리 사각형 선택과 가장자리 자동 스크롤을 지원합니다. ‘여러 개 선택’을 켜면 키보드 없이 클릭으로 추가·해제하며, 선택 해제 버튼도 제공합니다.
- 통계는 작성자 전체를 표시하고 검색합니다. 작성자를 고르면 해당 계정에 기록된 현재 파일에서 최근 게시물의 파일을 최대 8개 보여 줍니다. 없어진 파일과 중복 경로를 건너뛰며, 다른 작성자로 바꾸면 이전 이미지를 즉시 비우고 늦게 도착한 결과를 버립니다. 작은 화면에서는 작성자 목록의 높이를 제한해 이미지가 먼저 보이게 했습니다.
- 파일 목록에도 작성자 검색·선택을 추가했습니다.
- 기본 로그인은 ‘Edge에서 X 로그인’ 버튼입니다. 기존 프로필 대신 임시 프로필에서 로그인하고, 정상적인 x.com auth_token만 기존 DPAPI 저장 함수를 통해 보관합니다. 토큰 직접 입력은 펼쳐서 사용하며 cookies.txt도 유지합니다.
- 로그인 중 중복 실행·수동 연결 저장·연결 삭제·다운로드·예약 등록을 막습니다. 창을 닫으면 취소하며 앱 종료는 정리를 기다립니다. worker는 Tk 객체를 보유하지 않고 결과만 queue로 보냅니다.

## 이어서 수정한 문제

- Edge 실행용 프로세스가 0으로 종료돼도 실제 브라우저가 계속 실행될 수 있습니다. 프로세스 종료 코드 대신 이번 임시 프로필의 DevTools 연결과 페이지를 확인하며, 실행용 프로세스가 종료됐어도 Browser.close를 보냅니다.
- 다른 앱 인스턴스가 쓰는 임시 로그인 프로필을 삭제하지 않습니다. 재귀 삭제 직전에 이번 시도의 경로와 링크·정션 여부를 다시 확인합니다.
- 토큰 직접 입력을 펼칠 때 큰 글꼴에서 중첩 라벨의 너비 요청이 반복돼 UI가 멈추는 문제를 고쳤습니다.
- 대표 파일 목록을 고정된 후보 수로 잘라 실제 남아 있는 파일이 있어도 빈 결과가 나오던 문제를 고쳤습니다.
- 새 목록을 보여 줄 때 갤러리 드래그를 취소하고, 기록 창 종료 때 행 드래그 자동 스크롤 타이머를 제거합니다.

## 검증

- 전체 회귀 698개 실행: 695개 통과, 3개 생략, 실패 없음(391.3초). 로그: `.test-output/2.3.0/tests.log`. 생략은 Windows 링크 권한과 명시적으로 켜야 하는 실제 휴지통 검사입니다.
- 마지막 수정 사항의 검사 37개 통과. 로그: `.test-output/2.3.0/final-changes.log`. 전체 실행이 시작된 뒤 추가한 검사도 포함합니다.
- 실제 설치된 Edge를 headless + about:blank + 격리 프로필로 실행해 localhost CDP의 Storage.getCookies·Target.getTargets, 시간 초과, Browser.close와 프로필 제거를 확인했습니다. X에 로그인하거나 실제 토큰을 읽지 않았습니다.
- 1366×768 기준 밝은/어두운 테마의 로그인·파일 목록·갤러리·통계 화면 16개를 검토했습니다. 썸네일·기록은 임시 시험 데이터입니다. 네트워크 시도 0개. 기록: `.test-output/2.3.0/ui/manifest.json`.
- `build.ps1`로 2.3.0 폴더 실행 파일과 소스·라이선스 포함 ZIP을 만들었습니다. 브라우저 로그인 모듈이 PyInstaller 분석 결과에 포함됐으며, 패키지 실행 파일의 자체 점검도 통과했습니다. 로그와 보고서: `.test-output/2.3.0/build.log`, `.test-output/2.3.0/frozen-selftest.json`.

실제 X 계정의 로그인 완료 과정은 사용자 계정으로 확인해야 합니다. 정책으로 원격 디버깅이 차단된 PC에서는 토큰 직접 입력을 사용할 수 있습니다. 앱을 강제 종료하면 해당 시도의 임시 프로필이 남을 수 있습니다.
