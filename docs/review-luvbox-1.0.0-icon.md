# LuvBox 1.0.0 아이콘 수정판 검토

검토·수정일: 2026-10-12. Claude의 정식판 커밋 `94e119b`를 기준으로 검토했습니다. 앱 버전은 **1.0.0**으로 유지합니다. 이 문서는 배포 ZIP에 포함하지 않습니다.

## Claude 변경 확인

- 메인 화면·도움말·기록 창의 안내 정리, 미리보기 캐시의 AppData 경로 검사, 이전 이름의 예약 작업 전환을 검토했습니다. 추가 실행 회귀나 성능 보정이 필요한 문제는 발견하지 못했습니다.
- 기존 설정·로그인 정보·다운로드 기록의 경로와 형식을 유지합니다. 사용자가 지정한 저장 폴더도 그대로 사용합니다.
- 예약 검사 16개가 통과했습니다. 임시 모의 ScheduledTasks 함수로 이전 작업 검색·새 이름 등록·이전 작업 제거·예약 끄기를 확인했습니다. 실제 사용자 예약 작업을 조회하거나 변경하지 않았습니다.

## 수정

- 최신 사용자 참고 이미지에 맞춰 작은 빨간 하트 윤곽과 검은색에 가까운 둥근 사각형으로 아이콘을 다시 그렸습니다. 사각형 바깥 모서리는 투명합니다.
- PNG와 16·24·32·48·64·128·256px ICO를 함께 생성했습니다. 창·작업표시줄·탐색기용 실행 파일의 아이콘에 같은 디자인을 사용합니다.
- GitHub 저장소 이름을 `chobby-f/LuvBox`로 바꾸고 로컬 origin 주소를 갱신했습니다.
- VS Code 실행 구성·workspace 파일·개발 안내의 현재 배포 경로를 LuvBox로 맞췄습니다. 기존 사용자 데이터 호환성에 필요한 내부 이름은 유지합니다.

## 검증

- 전체 오프라인 회귀: **766개 중 763개 통과, 3개 생략**, 340.796초. 생략은 링크 생성 권한에 따른 검사입니다.
- `build.ps1` 성공. 앱·폴더·ZIP 이름은 `LuvBox-1.0.0`입니다.
- 한글 경로에 배포 ZIP의 앱 파일 2,924개를 풀어 실행 파일 자체 점검 성공: `ok=true`, `frozen=true`, `version=1.0.0`. 임시 앱 데이터와 파일만 사용했습니다.
- 실행 파일에 들어간 7개 크기의 아이콘이 소스 ICO와 픽셀 단위로 일치합니다. frozen 앱 모듈 22개도 현재 Python 소스와 일치합니다.
- ZIP CRC·SHA256, 소스 파일 1,599개·앱 파일 2,924개 바이트 일치 검증 통과. 개인 설정·DB·인증정보·개발 검토 문서·옛 아이콘·삭제 모듈은 없습니다. `source/LuvBox.code-workspace`를 포함합니다.

공개 `v1.0.0` 태그는 최초 정식판을 유지합니다. 기존 릴리스의 ZIP·SHA256을 수정판으로 교체하고, 릴리스 본문에 수정 커밋 링크와 배포 ZIP의 `source/`가 대응 소스임을 표시합니다. GitHub의 자동 생성 소스 ZIP은 최초 태그의 소스로 남습니다.

실제 X 계정에 요청하거나 사용자의 설정·로그인·기록·미디어를 바꾸지 않았습니다.
