# 리팩토링과 완성도 검수

2026-10-15, LuvBox 1.0.0 소스 기준입니다. 앞서 적용한 성능 개선을 유지하면서 작업의 책임·중단·오류 정리를 검토했습니다.

## 구조 정리

- 갤러리 작업을 파일 읽기, 제한된 캐시 관리, 결과 전달로 나눴습니다. 작업 취소 확인도 각 단계의 경계에 둡니다.
- DB 목록 조회의 커서 소유권과 읽기 트랜잭션을 공통 함수로 모았습니다. 이미 시작된 트랜잭션은 임의로 끝내지 않습니다.
- 미리보기 경로 허용 검사를 한곳에서 사용합니다. 사라진 파일의 설명 구성과 이미지 읽기를 분리하고, 기존 백그라운드 로더를 캐시 읽기에도 사용합니다.
- GIF 샘플링의 시간 누적을 별도 객체로 나눠 반복 재생의 남은 시간을 유지합니다.

## 재현한 문제와 수정

| 확인한 상황 | 수정 후 동작 |
| --- | --- |
| 갤러리를 바꾸는 동안 이전 파일의 상태 확인·디코딩이 늦게 끝남 | 취소된 요청은 다음 디코딩이나 선택적 미리보기 저장을 시작하지 않습니다. |
| 짧고 빠른 GIF가 매번 첫 프레임으로만 표시됨 | 반복 사이에도 샘플링 시간을 이어가며 애니메이션을 표시합니다. 남은 시간을 늘리거나 버리지 않습니다. |
| 기록 읽기 중 디코딩 오류의 traceback이 커서를 붙잡음 | 오류가 남아 있어도 커서를 닫고 DB 파일 잠금을 해제합니다. |
| 통계와 사라진 파일을 만드는 사이 다른 연결이 기록을 갱신함 | 한 번의 결과는 같은 SQLite 읽기 스냅샷을 사용합니다. |
| CSV를 쓰다가 뒤쪽 행 읽기·디스크 쓰기·최종 교체가 실패함 | 임시 CSV만 정리하고 기존 보고서는 유지합니다. 전체 성공 후에만 교체합니다. |
| 외부 프로그램이 DB를 잠가 백업의 재시도가 끝나지 않음 | 제한 시간이 지나면 중단하고 마지막 정상 백업을 보존합니다. |
| 사라진 파일을 고를 때 작은 미리보기 캐시의 응답이 늦음 | 화면은 계속 조작할 수 있고, 현재 선택의 결과만 표시합니다. 창을 닫은 뒤에는 이미지를 적용하지 않습니다. |
| 개발용 FFmpeg가 MP4 이름의 재생목록을 자동 판별함 | 선택한 MP4 입력 형식을 명시해 다른 파일을 따라 읽지 않습니다. |

## 검증

- 각 문제에 재현·회귀 검사를 추가했습니다. 전체 회귀 검사는 **1,021개 중 1,017개 통과, 4개 생략**이며, 앱 자체 점검은 `ok: true`입니다. 격리된 앱 데이터·임시 DB·생성 미디어에서 수행했습니다.
- 생략된 항목 중 실제 Windows 휴지통 검사는 별도 실행해 **1개 통과**했습니다. 이 검사가 새로 만든 임시 파일만 이동했으며, 원본 소멸·이동된 내용·Shell 영수증을 확인했습니다. 기존 사용자 파일과 기존 휴지통 항목은 변경하지 않았습니다. 나머지 생략 3개는 Windows 심볼릭 링크 생성 권한 제한입니다.
- 라이트·다크 테마의 기본 화면 69장, 1280×720 화면에서 10장을 생성했습니다. 메인 화면, 로그인 연결, 설정, 예약, 도움말, 목록·갤러리·선택, 통계, 사라진 파일, 대화창을 검토했습니다. UI 검증의 네트워크 시도는 두 실행 모두 0회입니다.
- 전체 결과는 `.test-output/refactor-full-tests.log`, 실제 휴지통 검사는 `.test-output/refactor-native-recycle.log`에 있습니다. 화면 자료는 `.test-output/refactor-ui/manifest.json`과 `.test-output/refactor-ui-small/manifest.json`, 앱 자체 점검은 `.test-output/refactor-source-selftest.json`에 있습니다.

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -X utf8 entry.py --self-test .test-output\refactor-source-selftest.json
.\.venv\Scripts\python.exe -X utf8 tools\ui_qa.py --output .test-output\refactor-ui
```

실제 X 계정의 로그인·다운로드·요청 제한, 외부 서비스와의 연결 상태는 이번 오프라인 검증에 포함하지 않습니다. 이후 수행한 배포 EXE·ZIP 재빌드, 한글 경로의 실행 파일 자체 점검, 소스 일치·무결성·개인정보 제외 검증은 [수정판 배포 전 검증](verification.md#2026-10-15-수정판-재빌드와-배포-전-검증)에 기록합니다.
