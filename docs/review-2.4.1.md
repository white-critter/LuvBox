# 2.4.1 안내 문구 정리

검토·수정일: 2026-10-08. 기준은 `7a54f13`의 2.4.0입니다. 2.3.0 요청(드래그·여러 개 선택·로그인 창·긴 설명·작성자 통계) 가운데 남아 있던 ‘긴 설명 다듬기’를 마쳤습니다. 기능은 바뀌지 않습니다.

## 원칙

- 한 문장에는 한 가지만 쓰고, 해야 할 일을 앞에 둡니다.
- 같은 뜻의 안심 문구(“기존 기록은 보존했습니다”, “요청을 자동 반복하지 않습니다” 등)는 한 번만 둡니다.
- 휴지통 이동, 동기화 폴더의 삭제·재업로드, 요청 간격, 다시 받지 않기의 범위처럼 결정에 필요한 내용은 남깁니다.

## 바꾼 곳

- 화면에 보이는 70자 이상 문장 42개: 확인창(출처·작성자 기록, 기록 복구, GIF 변환, 다시 받지 않기, 다시 받기, 삭제), 사라진 파일 안내, 저장 결과·오류·요청 한도 메시지, 자동 저장 상태, 도움말, 진행 상세, 기록 위치 안내.
- 로그인 방식이 바뀌어 맞지 않던 안내: 연결 만료 시 ‘auth_token 다시 입력’ → ‘Edge에서 X 로그인’, 자동 저장·예약 실행의 ‘인증 토큰 연결’ → ‘브라우저 로그인 연결’, 로그인 방법 선택 오류.
- 예: 사라진 파일 탭 설명 3문장(158자) → “저장한 뒤 사라진 파일입니다. 필요하면 ‘다시 받기’, 일부러 지웠다면 ‘다시 받지 않기’를 누르세요. 다른 폴더로 옮긴 파일도 여기 나옵니다.”

## 그 밖의 수정

- `test_browse`의 Like 시기 통계 검사가 두 실행의 시작 시각이 Windows 시계 해상도 안에서 같아지면 실패하던 문제를 고쳤습니다. 다른 검사와 같이 실행 사이에 0.02초를 둡니다. 앱 동작과는 관계없습니다.
- `test_local_records`의 사본 변경 감지 검사 2개도 같은 원인으로 고쳤습니다(아래 검증 참고).

## 검증

- 전체 회귀 **714개 중 711개 통과, 3개 생략**(268.4초). 생략은 Windows 링크 생성 권한 검사 2개와 명시적으로 켜야 하는 실제 휴지통 검사 1개입니다. 로그: `.test-output/text241-full-tests.log`.
- 문구를 확인하던 검사 13개는 같은 의미의 새 표현을 확인하도록 바꿨습니다.
- 기록 사본 변경 감지 검사 2개가 Windows 시계 해상도에 따라 자주 실패하던 문제를 고쳤습니다. 다른 PC가 쓴 사본을 흉내 낼 때 실제 동기화처럼 나중 시각을 줍니다. 연속 12회 통과. 앱의 변경 감지(크기·수정 시각)는 그대로입니다.
- `build.ps1`로 `release/XlikeSaver-2.4.1` 폴더 빌드와 ZIP을 만들었습니다. 배포본 감사: ZIP CRC·SHA256, 소스 105개·앱 2,924개 파일 일치, 개인 설정·DB·쿠키 항목 0개. 한글 경로에 풀어 실행 파일 자체 점검 통과. 로그: `.test-output/text241-build.log`, `.test-output/text241-release-audit.json`, `.test-output/text241-frozen-selftest.json`.

실제 X 계정에 요청하거나 사용자의 인증정보·설정·기록·미디어를 바꾸지 않았습니다.
