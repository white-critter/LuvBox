# LuvBox 1.2.0 기능 개선과 종합 검토

기존 종합 검토를 바탕으로 저장·갤러리·계정·설정·작업 프로세스·로컬 파일 경계·배포 패키징을 다시 점검했습니다. 운영 미디어·로그인·DB를 초기화하거나 삭제하지 않으며 기존 계정·기록·파일명 호환성을 유지합니다.

## 기능 변경

- 갤러리와 저장 전 확인창의 고정 크기 제한을 없애 앱 창을 넓게 사용합니다. 창 최대화·복원, 본문 보기·접기를 제공합니다.
- 휠·버튼 확대/축소, 드래그 이동, 화면 맞춤, 지원하는 사진의 원본 100%를 제공합니다. 새 파일·닫기·숨김에서 확대와 이동을 초기화합니다. GIF·영상은 확대·화면 맞춤을 지원하며 원본 100%는 확인된 정지 사진에만 적용합니다.
- 미리보기의 이전·다음과 좌우 방향키가 현재 검색·정렬 결과를 따릅니다. 끝에서 순환하지 않고, 필요한 다음 페이지는 비동기로 읽습니다. 본문에 키보드 초점이 있을 때 방향키를 가로채지 않습니다.
- 저장 화면의 자세히 보기는 최근에 실제로 저장한 파일의 작성자·표시 이름·본문·게시 시각·원문과 정지 미리보기를 보여 줍니다. 건너뜀·진행률·이전 작업 이벤트는 표시 항목을 바꾸지 않습니다. GIF·영상은 첫 프레임 PNG만 표시합니다.

## 발견해 수정한 문제

1. **계정 설정 중복 저장과 로그인 불일치:** 계정 컨트롤러와 앱 컨트롤러가 설정을 따로 써 두 번째 쓰기가 실패하면 화면은 이전 계정, 암호화 로그인은 새 계정으로 남았습니다. 임시 두 계정·실제 Windows DPAPI와 실패하는 설정 저장소로 재현했습니다. 앱은 계정·폴더를 한 번에 저장하고, 실패하더라도 실제 연결된 계정과 화면을 맞춥니다. 폴더는 마지막 성공 값을 유지하며, 저장 작업은 설정 쓰기가 성공한 뒤에만 시작합니다. 다른 앱의 계정 변경을 무조건 되돌리는 쓰기는 추가하지 않았습니다.
2. **작은 사진의 불필요한 확대 디코딩:** 고정 2048×2048 요청이 작은 사진을 큰 버퍼로 만들 수 있었습니다. 확인된 사진은 원본보다 크게 디코딩하지 않고 긴 변 2048 이하로 맞춥니다. 실제 64×32 합성 사진으로 확인했습니다.
3. **원본 보기의 회전·파일 교체 경계:** 회전된 표시 크기를 원시 디코딩 크기로 쓰면 잘못 확대될 수 있었습니다. 원시·표시 크기를 분리하고, 양수 크기와 클립 영역으로 디코딩 출력 상한을 유지합니다. 원본 보기는 기본 1,600만 화소·한 축 16,384px·입력 64MiB 이하로 확인된 사진에 제한합니다. 새 파일로 바뀌어 비율이 달라진 경우와 EXIF 회전을 검사했습니다.
4. **브라우저 오류 안내:** 선택한 브라우저가 열리지 않았는데 시스템 기본 브라우저 설정을 고치도록 안내하던 문구를 실제 실행 경로에 맞췄습니다. 오류에 일회성 연결 주소나 토큰을 노출하지 않습니다.

## 안정성·성능·보안 보완

- 헤더 크기·회전 조회, 썸네일·영상 첫 프레임 생성은 UI 밖에서 수행합니다. PNG 뒤쪽 EXIF도 픽셀을 풀지 않고 제한된 청크로 확인합니다.
- 저장 상세 보기를 숨긴 동안에는 디코딩하지 않습니다. 디코딩 작업은 한 개와 가장 최근 대기 요청 한 개로 제한하며, 숨김·새 작업·종료 이후의 결과는 버립니다. 미디어는 수정하지 않고 PNG를 메모리에만 보관합니다.
- 큰 미리보기 문자열을 진행률마다 다시 전달하지 않도록 전용 변경 신호를 사용합니다. 진행률 100회 동안 미리보기 맵을 다시 발행하지 않는 회귀 검사를 추가했습니다.
- 파일 링크·클라우드 전용 파일·디코딩 중 파일 교체를 거부하고 이미지 출력·PNG 크기·영상 처리 시간을 제한합니다. 미리보기 생성 오류는 이미 성공한 저장 상태를 실패로 바꾸지 않습니다.
- 게시물 정보는 이미 받은 데이터에서 필요한 공개 필드만 제한된 길이로 복사하며 화면에서는 일반 텍스트로 표시합니다. 원문 열기는 고정된 X 게시물 주소만 허용합니다. 추가 X 요청·브라우저 프로필 읽기·쿠키 전달은 없습니다.
- 갤러리 이동은 기존 모델의 위치 인덱스를 재사용하고 선택·검색 세대로 오래된 결과를 배제합니다. GIF·영상의 숨김·닫기 파일 해제와 저장 승인 지연 절차를 유지합니다.

## 검증 범위

새 기능은 생성한 사진·GIF·MP4, 임시 앱 데이터와 합성 계정으로 실제 Qt 이벤트 루프에서 확인합니다. 680×480·1080×760·1600×1000 창, Windows 네이티브 창, 150% 배율, 확대·이동·페이지 이동·저장 상세 표시·종료를 포함합니다. 전체 회귀와 실제 EXE·배포 ZIP 검증 결과는 [검증 기록](verification.md)에 기록합니다.

실제 사용자 X 로그인·추가 인증과 장기 실사용 전체를 자동 테스트의 성공으로 대신하지 않습니다. 정식 확장 스토어 등록, 확장 없는 로그인 창, 운영 DB의 파괴적 변경은 이번 작업에 포함하지 않습니다.
