# 2.4.0 검토와 배포 기록

검토일: 2026-10-08. 2.3.0에서 이어 온 Claude 패치와 이번 추가 요청을 함께 포함합니다.

- 실행 파일, 메인 창, 기록 창과 기타 팝업의 아이콘을 투명한 하트·다운로드 그림으로 교체했습니다. Windows 작업표시줄에는 버전과 무관한 앱 ID를 사용합니다. 16~256px ICO를 포함합니다.
- 기록 · 통계의 파일 목록·갤러리, 작성자 목록·대표 이미지, 실행 기록, 사라진 파일, 삭제 기록에 우클릭 메뉴를 추가했습니다. 선택 안의 항목을 우클릭하면 다중 선택을 유지하고, 새 항목은 단독 선택합니다. 기존 기능과 기존 삭제 확인·저장 중 제한을 사용합니다. 단일 파일·트윗 열기는 우클릭한 항목을 대상으로 하며, 경로 복사와 삭제는 전체 선택을 대상으로 합니다.
- 같은 작성자를 연속 선택했을 때 진행 중인 대표 이미지 조회를 다시 시작하지 않습니다. 빈 결과도 재사용하되 새로고침이나 작성자 변경 때 다시 조회합니다.
- 소켓의 부분 수신에도 전체 제한 시간을 적용하고, 큰 수신 데이터의 누적 복사를 줄였습니다.
- 초 단위 갱신 시각이 같은 저장·삭제 기록을 합칠 때 병합 방향에 따라 삭제 전 경로가 되살아나는 문제를 수정했습니다. 실제 파일이 없는 경우 같은 시각의 명시적 삭제 상태를 우선하고, 실제로 존재하는 복원본이나 다른 위치의 파일은 유지합니다. 기존 병합 검사의 시각을 고정해 양방향·반복 병합을 검증합니다.
- Windows의 iconbitmap은 네이티브 창을 생성합니다. 숨겨진 창에 아이콘을 먼저 설정하면 이후 geometry 요청이 초기 200×200 크기로 남는 문제를 재현하고, 창 크기 요청 뒤 아이콘을 적용하도록 순서를 수정했습니다.
- 복구 검사에서 시험용 추가 셀 포인터가 페이지 끝의 실제 데이터에 따라 SQL로 읽히기도 했습니다. 실제 행은 그대로 두고 사용하지 않는 공간에 디코딩할 수 없는 시험 셀을 추가해 손상 조건을 고정했습니다. 제품의 복구 동작은 바꾸지 않았습니다.

## Edge 검은 화면

실제 설치된 Edge의 새 임시 프로필에서 `x.com/i/flow/login`의 제목과 스크립트가 로드됐지만 화면이 비는 현상을 재현했습니다. 0번 디버깅 포트 대신 로컬에서 고른 비어 있는 포트를 사용하고, 시작 10초 후 입력 칸 없이 비어 있는 X 로그인 페이지만 한 번 새로 불러옵니다. 사용자 입력 칸이 나타난 페이지에는 새로고침을 보내지 않습니다.

수정한 `sign_in`을 실제 Edge에서 실행한 확인에서는 처음에 빈 화면이었으며, 자동 복구 후 `x.com/i/jf/onboarding/web?mode=login`의 이메일·사용자 아이디와 소셜 로그인 화면이 표시됐습니다. 취소 후 worker 종료와 이번 임시 프로필 제거도 확인했습니다. 실제 계정·비밀번호 입력이나 실제 인증정보 저장은 하지 않았습니다. 증거: `.test-output/edge-verified.json`, `.test-output/edge-verified.png`.

시작 중 취소돼도 이번 브라우저 연결을 찾아 종료합니다. Edge 실행용 PID가 실제 브라우저 PID와 다를 때에도, 정상 종료 연결이 실패하면 이번 고유 `--user-data-dir`에 속한 Edge 프로세스만 정리합니다. 필수 UserDataDir 정책은 임시 프로필 옵션을 덮어쓰므로 전용 로그인 실행 전에 확인합니다. HTTP 프록시를 거치지 않는 loopback 연결과 응답 주소 검증을 적용했습니다.

참고: [Microsoft Edge DevTools Protocol](https://learn.microsoft.com/en-us/microsoft-edge/devtools/protocol/), [Edge UserDataDir 정책](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-browser-policies/userdatadir), [MDN webdriver](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/webdriver).

## 검토 범위

다운로드·재시작과 계정 보호, 로컬 기록·통계, 저장 경로 이전·백업, 인증정보 저장, 휴지통 삭제·누락 복구, ExifTool·FFmpeg, 미리보기·갤러리, 예약 실행, 테마·팝업, 패키징 및 테스트를 검토했습니다. 기존 데이터베이스 페이지 조회와 캐시를 유지하며, 확인된 중복 조회와 소켓 수신만 개선했습니다. 파일 관리의 경로 검증·잠금·원자적 저장·삭제 확인을 유지합니다.
