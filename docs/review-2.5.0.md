# 2.5.0 일반 삭제 제거·외부 파일·GIF 기록

검토일: 2026-10-11. 기준: `8c54921`의 2.4.4.

## 변경 범위

일반 파일 삭제는 탐색기 등에서 하도록 프로그램의 삭제 버튼·우클릭 메뉴·Delete 키·확인창·작업자와 Windows 삭제 모듈을 제거합니다. 다중 선택·드래그 선택·파일 열기·경로 복사와 사라진 파일의 다시 받기·다시 받지 않기·숨김 해제는 유지합니다.

기존 DB의 삭제 기록·재다운로드 선택·출처·작성자는 보존하며 ‘이전 삭제 기록’은 조회만 합니다. 병합·복구·중단 기록 정리와 복원 파일의 선택 해제도 기존 정책을 유지합니다. 새로고침의 파일 확인은 실제 파일을 삭제하지 않습니다.

사용자의 추가 지시에 따라 GIF 변환은 유지합니다. 새 다운로드 중 MP4 임시 파일 또는 기존 MP4에서 GIF 변환이 성공하면 원본 MP4를 정리합니다. 기존 파일은 변환 결과를 기록한 뒤 원본을 Windows 휴지통으로 옮깁니다. 실패·중단·원본 변경·휴지통 이용 불가 시 기존 MP4를 보존합니다. 성공 기록은 실제 GIF 경로를 가리키며, GIF가 사라지면 새로고침에서 목록·통계·사라진 파일에 반영합니다.

## 외부 삭제 대응 보완

정상 저장은 외부 삭제 파일의 완료 archive를 유지하여 지운 파일을 자동으로 되받지 않습니다. 사용자가 고른 다시 받기만 해당 파일의 키를 잠시 해제하며, 실패·중단이면 원래 키를 복원합니다. 이 동작은 변경하지 않습니다.

A에서 받은 기록을 B로 이전하고 A의 파일을 외부에서 삭제한 뒤, B에 같은 파일을 복사하면 선택한 다시 받기가 B 파일을 보고 다운로드를 생략했습니다. 그러나 기록 갱신은 사라진 A 경로만 확인하여 실제 B 파일을 다시 연결하지 못했습니다. 선택한 다시 받기는 예전 경로 다음으로 현재 출력 경로의 기존 파일도 확인합니다. 다른 물리적 사본에 예전 파일의 임베드 성공 상태를 적용하지 않고 출처·작성자를 다시 확인하며, 기존 저장 시각은 유지합니다.

검사와 자체 점검·화면 QA는 격리한 임시 파일만 사용합니다. 사용자의 실제 파일·설정·인증·기록·예약 작업은 변경하지 않습니다.
