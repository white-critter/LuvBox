# LuvBox 1.0.0 선택 파일 휴지통 기능 복구 검토

2026-10-12. 사용 한도 중단 이후 기존 작업을 확인하고 마무리했습니다. 버전은 1.0.0을 유지합니다.

## 변경 결과

- 기록·통계의 목록·갤러리에 선택 파일의 ‘휴지통으로 보내기’ 버튼과 우클릭 메뉴, Delete 키를 복구했습니다. 확인창에서 실제 파일 개수·용량을 표시하며 ‘이 계정에서 다시 받지 않기’는 기본으로 켜져 있습니다.
- Windows IFileOperation으로 휴지통 이동만 허용하고 이동 결과의 파일 식별·원래 경로·크기를 확인합니다. 사용할 수 없는 위치와 바뀐 파일은 건너뜁니다.
- 기존 삭제 의도/결과 기록을 재사용합니다. 다운로드 시각·출처·작성자·GIF 미디어 종류를 유지하며, 파일은 ‘사라진 파일’과 ‘삭제 기록’에 반영됩니다. 원래 위치에 복원하거나 다시 받으면 현재 파일 목록·통계에 반영됩니다.
- 계정 및 모든 관련 미디어 경로의 작업 잠금과 확인창 전후의 계정·폴더 검사를 적용했습니다. 사라진 저장 폴더를 다시 만들지 않습니다. 잠금 획득 실패 시 미완료 삭제 기록을 변경하지 않습니다.
- 중단은 현재 파일 처리 이후 적용하고, 앱과 기록 창 종료는 삭제 작업의 기록·스냅샷·잠금 정리까지 기다립니다. 중단·오류·정리 실패에서도 완료 이벤트를 전달하며 미완료 의도는 실제 삭제를 반복하지 않고 확인합니다.
- 작업 스레드는 Tk 객체를 보유하지 않습니다. 확인창 변수는 주 스레드에서 해제합니다. 기본 도움말과 사용 안내를 현재 기능에 맞췄습니다.

## 검증

- 전체 회귀 검사: 840개, 836개 통과·4개 생략, 358.512초. 기존 테스트의 가짜 기록 창 4곳에 새 delete_active 상태를 명시한 뒤 재실행했습니다. 생략은 Windows 심볼릭 링크 생성 권한 3개와 기본 opt-in 휴지통 실동작 검사 1개입니다.
- 별도 opt-in 실동작 검사: 새로 생성한 임시 파일 1개의 Windows 휴지통 이동과 $R/$I 원래 경로·크기·파일 식별 확인 통과(0.106초). 기존 개인 파일이나 휴지통 항목은 선택하거나 처리하지 않았습니다.
- 소스 자체 점검 통과. 임시 GIF의 삭제 기록·다시 받지 않기·복원 처리, 외부 삭제·복원, 기록 복구, GIF 변환, 메타데이터, 테마 및 다운로드 작업자 자체 점검을 포함합니다. 자체 점검의 이동은 임시 파일을 자체 임시 폴더로 옮기는 대역입니다.
- build.ps1 빌드와 한글 경로에 ZIP을 새로 풀어 실행한 frozen 자체 점검 통과(version=1.0.0, frozen=true, library_deletion=mock-recycle-journal-and-gif-restoration).
- 배포 감사 통과: frozen entry.py 및 패키지 24개 모듈이 현재 소스와 일치. ZIP CRC·중복·경로 검사, 소스 1,603개와 앱 파일 2,924개 바이트 일치, SHA256, 개인정보 제외, 개발 검토 문서 제외, 현재 아이콘 7개 크기 및 PNG/ICO 일치 확인.
- git diff --check 통과. 실제 X 계정 로그인을 통한 다운로드는 이번 오프라인 점검에서 실행하지 않았습니다.
