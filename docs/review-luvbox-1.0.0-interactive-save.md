# LuvBox 1.0.0 파일별 저장 확인 기능 검토

2026-10-12. 사진·동영상·GIF를 하나씩 확인하고 저장 여부를 선택하는 옵션을 추가했습니다. 버전은 1.0.0을 유지합니다.

## 변경 결과

- 기본은 기존 자동 저장 방식입니다. 메인 화면과 저장 설정의 ‘저장 전에 하나씩 확인’을 켜면 직접 시작한 저장과 선택한 파일의 다시 받기에서 확인창을 표시합니다. 진행 중에도 옵션을 켜거나 끌 수 있습니다.
- 확인창은 메인 화면 조작을 막지 않으며 ‘저장’, ‘이번엔 건너뛰기’, ‘이후 자동 저장’, ‘전체 작업 중단’을 제공합니다. 확인창을 닫거나 Escape를 누르면 전체 저장 작업을 중단합니다.
- 사진은 큰 미리보기로 표시하고 동영상·GIF는 처음 30초를 소리 없이 반복 재생합니다. 프레임 크기·재생 속도·대기 큐·디코더 작업 수를 제한하며, 멈춘 디코더는 감시 작업으로 종료합니다. 이미지나 영상을 읽지 못하면 안내를 표시합니다.
- 확인을 위해 미디어를 먼저 .part 임시 파일로 다운로드합니다. 선택한 저장 폴더가 동기화 폴더라면 승인 전 임시 파일도 동기화 대상이 될 수 있습니다. 승인은 최종 미디어 파일 저장과 다운로드 성공 기록을 남기는 기준입니다.
- ‘저장’ 승인 뒤에만 최종 경로로 옮기고 성공 기록과 중복 방지 archive를 등록합니다. GIF는 승인 이후 변환하며, GIF 저장에 성공하면 원본 MP4 임시 파일을 제거합니다. 변환 실패·용량 초과 시에는 기존 정책에 따라 원본 MP4로 저장할 수 있습니다.
- 건너뛰기는 이번 실행에만 적용됩니다. 해당 임시 파일을 정리하며 저장 성공·이미 저장됨·archive 등록으로 처리하지 않습니다. 다음 직접 저장에서 확인 옵션이 켜져 있으면 다시 확인하고, 옵션이 꺼져 있거나 예약 자동 저장이면 자동으로 저장될 수 있습니다.
- 새 Like 저장 중 거절한 항목이 있으면 완료 이력은 partial로 기록해 다음 quick 요청에서도 전체 목록을 확인합니다. 기존 저장 파일이 이어지는 종료 지점 뒤에 거절한 항목이 숨는 문제를 막습니다. 기존 파일의 archive 건너뛰기와 의도적 삭제의 다시 받지 않기 정책은 유지합니다.
- ‘사라진 파일’의 선택 재다운로드에서 거절한 항목은 기존 archive와 제외 선택을 유지합니다. 해당 항목은 필요할 때 ‘다시 받기’에서 다시 선택합니다. 선택 재다운로드는 일반 Like 목록의 quick 체크포인트가 되지 않습니다.
- 승인 대기 전후에 임시 파일의 일반 파일 여부·허용 경로·식별 정보를 검사하며, 최종 파일을 덮어쓰지 않습니다. 확인 중 파일이나 완료 마커가 바뀌면 안전하게 중단합니다. 이미 존재하는 최종 파일은 사용자 거절로 제거하지 않습니다.
- ‘저장’·‘이후 자동 저장’과 메인 옵션 OFF 전환은 디코더 종료와 Windows 원본 파일 핸들 해제를 확인한 뒤 작업자에게 전달합니다. 해제를 확인하지 못하면 승인 대신 중단합니다. 작업 스레드에는 Tk 객체나 UI 콜백을 전달하지 않습니다.
- 중단·앱 종료·확인창 닫기는 승인으로 해석하지 않습니다. 확인 대기 중 작업자와 창의 연결이 끊기거나 제어 파일이 손상되면 중단하고 임시 파일을 보존합니다. 제어 파일에는 실행 식별자·옵션·선택·연결 확인 시각만 기록하며 쿠키·토큰·미디어 요청 URL을 넣지 않습니다.
- Windows 예약 실행은 무인 실행을 유지합니다. 저장된 확인 옵션이 켜져 있어도 예약 작업의 confirm_each는 False로 설정하며 확인창을 기다리지 않습니다. 기본 사용 방법과 저장 안내에 이 차이를 명시했습니다.

## 검증

- 전체 회귀 검사: 901개, 897개 통과·4개 생략, 423.005초. 생략은 Windows 심볼릭 링크 생성 권한 3개와 기본 opt-in 휴지통 실동작 검사 1개입니다.
- 백엔드 관련 별도 검사: 152개 통과. 새 확인 흐름 22개, 기존 다운로드 core 59개, 미디어 처리 36개, GIF 변환 21개, 누락 파일 재다운로드 14개를 포함합니다. 승인 전 최종 파일·archive·성공 이력 부재, 건너뛰기 이후 전체 확인, GIF 승인 후 변환, 기존 파일·변경된 임시 파일 보호, 중단·확인 연결 실패·선택 재다운로드 정책을 확인했습니다.
- 프리뷰 관련 검사: 18개 통과(Tk 확인창 8개·디코더 10개). 실제 생성한 MP4·GIF의 무음 프레임 재생, 프레임 큐 제한, 닫기·디코더 종료·원본 핸들 해제 후 파일 정리, UI 주 스레드 표시와 이미지 해제를 확인했습니다.
- 자체 제작한 임시 GIF 확인창을 light·dark 두 테마에서 열어 720×650 화면을 캡처하고 시각 점검했습니다. 버튼·텍스트·움직이는 GIF 표시가 정상이며, 선택 후 디코더 핸들 해제도 통과했습니다. 캡처에는 개인 미디어가 포함되지 않습니다.
- IPC 검사 10개와 메인 앱 연결 검사 11개 통과. 실행별 선택 식별자, 손상된 제어 파일, 부모 연결 종료, 중단, 모드 전환, 비모달 확인창, 재다운로드 후속 안내를 확인했습니다. 별도 검사는 전체 회귀 검사에도 포함됩니다.
- 소스 자체 점검 통과(ok=true, version=1.0.0, frozen=false). interactive_save=muted-video-gif-playback-and-nonmodal-choice이며 기존 GIF 변환·메타데이터·삭제 및 복원·기록 복구·테마·작업자 자체 점검도 통과했습니다.
- build.ps1 빌드와 최종 ZIP 재포장 완료. ZIP을 새 한글 경로에 풀어 실행한 frozen 자체 점검 통과(ok=true, version=1.0.0, frozen=true, interactive_save=muted-video-gif-playback-and-nonmodal-choice).
- 최종 배포 감사 통과: frozen entry.py 및 패키지 27개 모듈이 현재 소스와 일치합니다. review·review_gui·review_preview 모듈과 새 테스트 5개를 소스 ZIP에서 확인했습니다. ZIP CRC·중복·경로 검사, 소스 1,611개와 앱 파일 2,924개 바이트 일치, SHA256, 아이콘 7개 크기 및 PNG/ICO 일치를 확인했습니다.
- 쿠키·토큰·세션·기록 DB·개인 설정·브라우저 프로필·IPC 제어 및 선택 파일·임시 다운로드·개발 검토 문서가 배포 ZIP에 포함되지 않은 것을 확인했습니다. 실제 X 계정 로그인이나 X 미디어 다운로드는 이번 오프라인 점검에서 실행하지 않았습니다.
