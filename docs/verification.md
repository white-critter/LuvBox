# LuvBox 1.0.0 검증

2026-10-14. 전체 앱 모듈과 진입점·빌드·배포 경로를 검토하고 재현된 결함과 이름 변경 호환성을 보완했습니다. 버전은 **1.0.0**을 유지합니다.

- 프로젝트 폴더·Python 패키지·새 앱 데이터·DB·임시 파일·메타데이터 표식을 LuvBox 이름으로 통일합니다. 이전 이름은 기존 데이터를 가져오는 호환 입력으로만 인식합니다. 설정·암호화 로그인·완료 임시 파일·기록 사본·백업을 이어 쓰며, 이전에 실패하면 빈 데이터로 시작하지 않습니다.
- HTML·일반 텍스트로 응답한 API 서버 오류도 전체 저장을 중단하고 오류로 기록합니다.
- 확인 옵션이 꺼진 일반·예약 다운로드도 다른 프로그램이 만든 같은 이름의 파일을 덮어쓰지 않습니다. 완료 임시 파일은 보존해 로컬에서 이어서 마무리합니다.
- 기존 MP4의 GIF 변환은 생성한 GIF가 바뀌었으면 원본 MP4를 보존합니다. 실패 정리에서도 다른 프로그램이 교체한 GIF를 지우지 않습니다.
- 출처·작성자 기록은 NTFS 보조 스트림·생성 시각·파일별 접근 권한을 보존하고, 보존 실패 시 원본을 유지합니다. 이전 작성자 표식도 읽을 수 있습니다.
- 크기·수정 시각이 같아도 실제 파일이 교체되면 선택 미리보기와 갤러리 캐시를 갱신합니다.
- 서로 다른 작업의 상위·하위 저장 폴더가 겹치면 동시 쓰기를 막습니다. 독립된 폴더와 한 작업이 관리하는 여러 이전 폴더는 허용합니다.

Windows 전체 회귀 검사 **988개: 984개 통과, 4개 생략**. 이후 추가한 이전 기록의 사라진 저장 폴더 감지 회귀 2개를 포함한 관련 23개 검사도 통과했습니다. 생략은 심볼릭 링크 권한 3개와 명시적으로 선택해야 하는 실제 휴지통 검사 1개입니다. 회귀 검사는 자체 임시 앱 데이터·미디어·DB를 사용합니다. 실제 Windows DPAPI 구형 세션 복호화, 파일 보조 스트림·접근 권한 보존, 프로세스 간 중첩 폴더 잠금도 검사합니다. 실제 X 계정 다운로드는 오프라인 검증에 포함하지 않았습니다.

배포 전 소스 자체 점검, 한글 경로의 새 실행 파일 점검, ZIP CRC·SHA256·현재 소스와 실행 파일 일치·개인정보 제외를 확인합니다. 배포 파일의 SHA256은 `SHA256-1.0.0.txt`와 GitHub 릴리스에서 확인할 수 있습니다. 현재 수정판 소스는 릴리스 설명의 커밋 링크와 배포 ZIP의 `source/`에 있습니다. 기존 v1.0.0 태그와 Git 커밋 이력은 보존합니다.

## 2026-10-15 성능 개선 소스 검증

기록 조회 인덱스·삭제 여부 필터, 갤러리 선택 갱신·썸네일 큐·캐시 재사용, 사진 미리보기의 축소·회전 순서를 개선했습니다. 손상된 DB의 읽기 오류는 복구 안내로 연결하고, 디코딩 오류 시 커서를 정리해 파일 잠금이 남지 않게 보완했습니다. 측정 조건·수치·저장 공간과 쓰기 비용은 [성능 검증](performance.md)에 기록합니다.

전체 회귀 검사 **1,002개: 998개 통과, 4개 생략**. 소스 앱 자체 점검도 `ok: true`입니다. 이 검증은 임시 DB·생성 미디어·격리한 앱 데이터에서 수행했으며 실제 X 계정 다운로드는 포함하지 않습니다. 이번 성능 개선의 배포 EXE·ZIP 재빌드는 수행하지 않았습니다.

## 2026-10-15 리팩토링·완성도 검수

갤러리 디코더, DB 커서·읽기 트랜잭션, 미리보기 권한 검사와 설명 구성, GIF 샘플링을 역할별로 정리했습니다. 작업 취소 지연, 짧은 GIF의 정지·시간 왜곡, 오류 후 DB 파일 잠금, 동시에 갱신된 기록의 집계 불일치, 실패한 CSV 내보내기의 기존 파일 훼손, 백업 무한 재시도, 작은 미리보기의 화면 대기를 보완했습니다. 개발용 FFmpeg에서도 MP4 이름의 재생목록을 따라 읽지 않습니다.

전체 회귀 검사 **1,021개: 1,017개 통과, 4개 생략**. 소스 앱 자체 점검은 `ok: true`입니다. 실제 Windows 휴지통 검사는 자체 임시 파일로 별도 실행해 1개 통과했으며, 남은 생략 3개는 심볼릭 링크 생성 권한 제한입니다. 라이트·다크 69개 화면과 1280×720 환경의 10개 화면을 검수했고, UI 검증에서 네트워크 시도는 0회였습니다.

자세한 수정·검증 범위와 재현 명령은 [리팩토링 검수](refactoring-review.md)에 있습니다. 실제 X 계정 연결·다운로드와 배포 EXE·ZIP 재빌드는 이번 검증에 포함하지 않았습니다.

## 2026-10-15 수정판 재빌드와 배포 전 검증

성능 개선·리팩토링 소스의 최종 독립 검수에서 추가 출시 차단 결함을 발견하지 못했습니다. `build.ps1`로 Windows 폴더형 EXE와 소스·라이선스를 포함한 ZIP을 재빌드했습니다. 새 성능 측정 도구와 검수 문서도 배포 소스의 명시적 포함 목록에 추가했습니다. `pip check`와 `git diff --check`를 통과했습니다.

배포 ZIP의 CRC·SHA256을 확인하고, EXE에 포함된 앱 모듈 **28개와 진입점**을 현재 소스에서 컴파일한 코드와 대조했습니다. ZIP의 현재 로컬 소스 **1,624개**, 실행 폴더 파일 **2,924개**가 원본과 일치합니다. 설정·로그인 세션·쿠키·DB·사용자 로그·부분 다운로드 파일은 포함되지 않았습니다. ExifTool의 공식 테스트용 Geotag 로그와 개발용 `.vscode/settings.json`은 사용자 데이터와 구분해 확인했습니다.

ZIP을 공백을 포함한 한글 경로에 풀어 실행한 EXE 자체 점검은 **종료 코드 0, `ok: true`, `frozen: true`**입니다. 사진·동영상·GIF, 출처·작성자 메타데이터, DB 복구·이전, 테마·폰트·대화창, 작업 프로세스의 인증 전 중단을 확인했습니다. ZIP에 담긴 소스로 실행한 자체 점검도 `ok: true`입니다. 앞선 전체 회귀 검사 **1,021개 중 1,017개 통과·4개 생략**, 별도 실제 휴지통 검사 1개 통과, UI 79개 화면 검수 결과를 함께 적용합니다. 실제 X 로그인·다운로드는 수행하지 않았습니다.

실행 파일은 코드 서명되지 않았습니다. 첫 실행은 Windows Smart App Control에 차단됐고 Code Integrity 이벤트 3077·3033을 확인했습니다. 사용자가 해당 설정을 끈 뒤 동일한 EXE로 위 실행 점검을 통과했습니다. 공인 서명 환경에서의 검증은 포함하지 않습니다.

개발 검증 자료는 `.test-output/release-build.log`, `.test-output/release-validation.json`, `.test-output/release-frozen-selftest.json`, `.test-output/release-packaged-source-selftest.json`에 있습니다. 최종 SHA256은 `release/SHA256-1.0.0.txt`로 제공합니다. 기존 v1.0.0 태그는 보존하고 수정판 소스 커밋을 릴리스 설명에 연결합니다.

## 2026-10-16 자동 미리보기·아이콘·보안 경계 검증

다운로드 완료 파일의 작은 미리보기를 자동 보관하며, 일시적인 캐시 잠금 뒤와 중단·건수 제한 종료 때도 재시도합니다. 기록 DB 쓰기 실패와 미리보기 보관을 분리했고, 방문한 기존 파일은 미리보기가 없을 때만 보완합니다. 수동 도구는 이전 파일·누락 항목을 위한 보완 기능으로 표시합니다. 사진·영상·GIF와 폴더 정리 3가지·계정별 폴더 여부의 조합을 생성 미디어로 검사했습니다.

Tk 기본 아이콘과 모든 Tk/Toplevel의 작업표시줄 식별 정보를 보완했습니다. 아이콘 픽셀, native wrapper 재생성, 반복 창 생성·종료 시 핸들 정리를 검사했습니다. 사용자 화면의 깃털 자체는 소스 실행에서 직접 재현하지 못했으며, 기본 아이콘·독립 창의 식별 정보가 빠지는 경로를 재현해 보완했습니다.

공유 기록의 외부 경로 권한 확대, 로그인 연결의 로컬 포트 선점, 위장 이미지의 외부 렌더러 선택, 압축 메타데이터의 무제한 출력·메모리 사용, 재패키징 시 임의 파일 포함 경로를 보완했습니다. 자세한 재현 조건·수정·남은 범위는 [보안 검토](security-review.md)에 있습니다. 실제 Edge의 새 임시 프로필·빈 페이지에서 전용 파이프 통신과 디버깅 TCP LISTEN 0개, 정상 종료·프로필 정리를 확인했습니다.

전체 회귀 검사 **1,069개 중 1,064개 통과, 5개 생략**(`security-full-tests-final.log`, 404.577초). 생략 중 실제 Windows 휴지통 검사는 자체 임시 파일로 별도 실행해 **1개 통과**했고, 나머지 4개는 심볼릭 링크 생성 권한 제한입니다. 소스 자체 점검은 `ok: true`입니다. 라이트·다크의 기본 화면 8개와 1280×720 화면 6개를 검수했고 네트워크 시도는 두 실행 모두 0회였습니다. 고정 의존성 15개의 설치 버전 일치·OSV 조회 결과 0건, `pip check`, 소스·PowerShell 문법과 `git diff --check`를 확인했습니다.

Windows EXE·ZIP을 재빌드했습니다. ZIP CRC·SHA256, EXE의 앱 모듈 **29개와 진입점**의 소스 일치, ZIP의 로컬 소스 **1,629개**·실행 폴더 파일 **2,924개**의 원본 일치와 개인정보 제외를 확인했습니다. 새 보안 검토 문서와 테스트·메모리 제한 모듈도 배포 소스에 포함합니다.

한글·공백 경로에 푼 최종 EXE 자체 점검은 **종료 코드 0, `ok: true`, `frozen: true`**이며, 포함 소스 자체 점검도 `ok: true`입니다. 실제 X 계정 로그인·다운로드는 수행하지 않았고, 코드 서명은 적용하지 않았습니다. EXE 실행 검수는 Smart App Control이 꺼진 환경에서 수행했습니다.

최종 자료는 `.test-output/security-full-tests-final.log`, `security-source-selftest.json`, `security-native-recycle.log`, `security-release-build.log`, `security-release-validation.json`, `security-release-frozen-selftest.json`, `security-release-packaged-source-selftest.json`과 `security-ui/manifest.json`, `security-ui-small/manifest.json`, `security-audit/`에 있습니다. 체크섬은 `release/SHA256-1.0.0.txt`로 제공하며 기존 v1.0.0 태그는 보존합니다.
