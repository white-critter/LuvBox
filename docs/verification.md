# LuvBox 1.0.0 검증

2026-10-14. Claude Code Cloud의 `ed75470`까지 변경한 네 커밋을 Windows에서 검토했습니다. 버전은 1.0.0을 유지합니다.

- 출처·작성자 재기록의 완료 안내에 가장 많은 실패 이유를 고정된 안전한 문구로 표시합니다.
- 같은 1.0.0 번호로 다시 빌드한 설치본은 실행 파일 정보를 사용해 테마 이미지 캐시를 갱신합니다.
- 확인창에서 중단해 남겨 둔 완료 `.part`는 다음 실행에서 요청 없이 사용합니다. 완료 표식이 없는 불완전한 파일의 416 응답은 기존처럼 중단합니다. 표식은 필요한 중단 경로에서만 남기며, 표식을 기록하지 못해도 원본과 실행 결과를 보존합니다.
- 내부 `xlikesaver` 패키지·앱 데이터 폴더·DB 이름과 로그인 암호화 형식은 기존 데이터 호환성을 위해 유지합니다. 사용자 사진·영상·로그인·설정·실제 다운로드 기록은 정리 대상에 포함하지 않습니다.

Windows 전체 회귀 검사 **952개: 948개 통과, 4개 생략**. 생략은 심볼릭 링크 권한 3개와 명시적으로 선택해야 하는 실제 휴지통 검사 1개입니다. 완료 파일 재사용·중단·GIF·변경 파일 보호 관련 별도 14개 검사도 통과했습니다. 실제 X 계정 다운로드는 이번 오프라인 검증에 포함하지 않았습니다.

현재 사용 안내와 개발 안내만 유지하고, 옛 개발 버전별 검토 문서와 개인 IDE 설정은 제거합니다. Git 커밋 이력과 제3자 소스·런타임·라이선스·재현 자료는 유지합니다. 2.x 릴리스·태그는 사용자 승인에 따라 정리하고 v1.0.0 태그를 보존합니다.

배포 전에는 소스 자체 점검, 한글 경로의 실행 파일 점검, ZIP CRC·SHA256·소스 일치·개인정보 제외를 확인합니다. 배포 파일의 SHA256은 `SHA256-1.0.0.txt`와 GitHub 릴리스에서 확인할 수 있습니다. 현재 수정판 소스는 릴리스가 가리키는 커밋 또는 배포 ZIP의 `source/`에 있습니다.
