# LuvBox 검증

이 문서는 현재 지원하는 Qt 앱의 검사 절차와 최신 완료 결과를 기록합니다. 과거 UI·버전별 전체 원문은 [1.2.0 검증 기록](https://github.com/white-critter/LuvBox/blob/v1.2.0/docs/verification.md)에 보존합니다. 실행하지 않은 항목이나 생략된 항목을 통과로 보고하지 않습니다.

## 검사 절차

[개발 안내](development.md)의 고정 입력·의존성 확인, 전체 unittest, 소스 자체 점검과 오프라인 저장 초기화를 실행합니다. 테스트는 임시 앱 데이터·생성한 미디어·합성 계정을 사용합니다. 링크 생성 권한이나 선택적 Chromium/Playwright가 없으면 해당 검사는 사유와 함께 생략될 수 있습니다.

`build.ps1`은 PyInstaller 전에 프로젝트 입력을 기록하고 빌드 후 불변 여부와 EXE·실행 폴더 전체 파일의 해시를 확인합니다. Python·QML·도구·배포 문서·의존성 또는 봉인한 런타임이 바뀌면 다시 빌드해야 합니다. 실제 EXE의 Qt 화면·종료와 오프라인 저장 시작 검사도 통과한 뒤에만 ZIP을 만듭니다. 직접 패키징에도 같은 입력 기록과 EXE별 시작 보고서가 필요합니다.

배포 검증은 ZIP CRC, 실행 파일·런타임·소스·라이선스, 체크섬과 개인정보 제외를 확인합니다. 공개 전 업로드 파일을 다시 받아 해시를 대조하고 한글·공백 경로에서 실행합니다. 세부 로그와 합성 화면은 `.test-output/`에 보관하며 배포 소스에 넣지 않습니다.

## 2026-10-30 1.3.4 종합 검토

- Python 3.12.14에서 첫 전체 회귀 1,126개(7개 환경 생략)를 통과한 뒤 새 공식 보안 공지를 확인해 프로젝트 전용 3.12.16으로 갱신했습니다. 원본 자산 SHA-256을 확인했고 기존 고정 패키지·설정은 유지했습니다. 새 런타임은 OpenSSL 3.5.9·Expat 2.9.0이며 시스템·Codex 런타임은 바꾸지 않았습니다. 이후의 최종 회귀와 빌드는 새 런타임을 사용합니다.
- 새 런타임의 원본 라이선스 20개와 빌드 인벤토리를 대응하는 전체 배포에서 확보했습니다. 두 원본 자산의 공식 SHA256SUMS와 실제 해시, 현재 실행 파일·DLL 8개의 일치를 확인했으며 Git에서도 원본 줄바꿈 바이트를 보존합니다. 새 런타임에서 100%·150%·200% UI·연결 장면 6회도 다시 통과했습니다.
- Windows Python 3.12.16 전체 회귀는 **1,134개 중 1,127개 통과·7개 생략**, 실패·오류 없음(330.192초)입니다. 생략은 심볼릭 링크 권한 5개·선택적 Chromium/Playwright 1개·기본 비활성 네이티브 휴지통 검사 1개입니다. 검사 전후 소스·배포 입력 250개 해시가 같았습니다. `pip check`, 고정 빌드 입력·보안 버전 검사, 소스 자체 점검과 오프라인 다운로드 초기화도 통과했습니다.
- 배포 해시 검사에서 PATH의 Poppler OpenSSL DLL 혼입을 발견해 빌드 hook과 패키징 출처·실제 파일 검사를 보완했습니다. 관련 56개 검사(2개 링크 권한 생략)와 독립 회귀 9개를 통과했고, 이 최종 소스의 추가 전체 회귀·재빌드·업로드 검증 수치는 1.3.4 릴리스 설명에 기록합니다.
- 빌드와 전체 검사를 함께 실행하는 중 중단 회귀의 테스트 PID 파일이 기록 전 읽히는 경합을 발견했습니다. 테스트용 자식 프로세스는 완성된 PID를 임시 파일에서 원자적으로 공개하도록 보완했습니다.
- 전체 회귀 종료 시 기존 urllib3의 SSL 옵션 사용 중단 경고와 PySide 관련 GC 128개 객체의 `ResourceWarning`이 남았습니다. 테스트 실패나 장기 실행 메모리 누수 부재로 해석하지 않습니다. 상세 로그는 `.test-output/unittest-1.3.4.log`와 결과 JSON에 보존합니다.
- 제품 Pretendard 글꼴과 실제 Windows Qt 화면에서 680×480·1080×760 창을 100%·150%·200% DPI로 검사했습니다. 갤러리 오류가 있을 때 최소 창의 목록 폭은 809→632px, 새로고침 x 좌표는 752→575px(버튼 폭 81px)로 복구됐습니다. 긴 공백 없는 경로는 632×85px로 줄바꿈하며 오류를 빈 목록으로 안내하지 않습니다.
