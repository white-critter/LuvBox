# LuvBox 검증

이 문서는 현재 지원하는 Qt 앱의 검사 절차와 최신 완료 결과를 기록합니다. 과거 UI·버전별 전체 원문은 [1.2.0 검증 기록](https://github.com/white-critter/LuvBox/blob/v1.2.0/docs/verification.md)에 보존합니다. 실행하지 않은 항목이나 생략된 항목을 통과로 보고하지 않습니다.

## 검사 절차

[개발 안내](development.md)의 고정 입력·의존성 확인, 전체 unittest, 소스 자체 점검과 오프라인 저장 초기화를 실행합니다. 테스트는 임시 앱 데이터·생성한 미디어·합성 계정을 사용합니다. 링크 생성 권한이나 선택적 Chromium/Playwright가 없으면 해당 검사는 사유와 함께 생략될 수 있습니다.

`build.ps1`은 PyInstaller 전에 프로젝트 입력을 기록하고 빌드 후 불변 여부와 EXE·실행 폴더 전체 파일의 해시를 확인합니다. Python·QML·도구·배포 문서·의존성 또는 봉인한 런타임이 바뀌면 다시 빌드해야 합니다. 실제 EXE의 Qt 화면·종료와 오프라인 저장 시작 검사도 통과한 뒤에만 ZIP을 만듭니다. 직접 패키징에도 같은 입력 기록과 EXE별 시작 보고서가 필요합니다.

배포 검증은 ZIP CRC, 실행 파일·런타임·소스·라이선스, 체크섬과 개인정보 제외를 확인합니다. 공개 전 업로드 파일을 다시 받아 해시를 대조하고 한글·공백 경로에서 실행합니다. 세부 로그와 합성 화면은 `.test-output/`에 보관하며 배포 소스에 넣지 않습니다.

## 2026-11-10 1.5.3 중복 스캔 최적화·해시 비교 고속화·일괄 태그 및 통계 UX 보강

- **중복 이미지 스캔 쿼리 최적화**: 10,000건 제한과 테이블 조인을 제거한 경량 전용 쿼리(`photo_records_for_scan()`)를 도입하여 1만 장 이상의 대용량 보관함에서도 누락 없이 모든 사진을 신속하게 검사하도록 개선했습니다.
- **유사 이미지 클러스터링 고속화 (4배 이상 속도 향상)**: 64비트 dHash 거리 비교 시 해시 문자열 파싱을 사전 정수 변환하여, Python 3.12 네이티브 `bit_count()` 기반 비트 연산으로 O(N²) 구간의 연산 속도를 4배 이상 최적화했습니다.
- **클러스터 저장 트랜잭션 청크 분할**: 대규모 중복 탐지 시 수만 개의 cluster_id를 한 번에 업데이트하지 않고 1,000개 단위 청크로 분할하여 SQLite 락 대기 및 메모리 사용량을 최소화했습니다.
- **일괄 태그 추가 및 태그 삭제 UX 개선**: 다중 선택 일괄 태그 팝업에 `Esc` 및 외부 클릭 닫기(`closePolicy`)와 자동 포커스(`forceActiveFocus`)를 적용하여 팝업이 뜨자마자 키보드로 태그를 입력할 수 있도록 개선했습니다. 미리보기의 태그 삭제(×) 버튼 터치 영역을 확대하여 오작동을 방지했습니다.
- **통계 대화상자 반응형 레이아웃 보강**: 최소 창 크기에서도 통계 요약 카드 텍스트가 잘리지 않도록 줄임표(elide) 처리를 적용하고, 월별 추이 건수 레이블의 최소 폭을 확보해 수만 건 이상의 통계 수치도 온전히 표시됩니다.

- 전체 회귀 **1,190개 중 1,183개 통과·7개 생략, 실패·오류 0**(371.226초). 생략은 이전과 같이 심볼릭 링크 생성 권한이 없는 검사 5개, 선택적 Chromium/Playwright 통합 1개, 명시적으로 켜야 하는 Windows 휴지통 검사 1개입니다. 종료 시 Qt GC 객체 140개의 `ResourceWarning`이 남았습니다. 1.4.7은 139개였습니다. 이 경고만으로 창을 열 때마다 쌓이는 누수라고 보지는 않으며, 제품 종료는 작업 타이머를 멈추고 QML 엔진을 지우는 기존 순서입니다.
