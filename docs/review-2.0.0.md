# 2.0.0 화면 개편 검증

검증일: 2026-10-06. 1.11.1 안정화와 1.11.2 실제 파일 통계 개선을 포함합니다.

## 화면과 사용 흐름

- 사이드 메뉴와 저장 대시보드: 계정·연결·저장 폴더를 확인한 뒤 저장 시작.
- 라이트·다크 공통 디자인: Pretendard, 둥근 카드·버튼·탭, 스위치, 부드러운 진행 막대.
- 저장 설정: 저장 위치·미디어·확인 방식으로 나누고 저장·취소 버튼을 고정 표시.
- 라이브러리: 파일·실행 기록·통계 탭, 검색·기간 필터, 목록·갤러리, 미리보기와 페이지 이동.
- 파일 관리: 기존 파일의 출처·작성자 기록과 MP4 GIF 변환을 별도 창에서 실행.
- 작은 창과 큰 글꼴: 메뉴·도구 막대·페이지 이동·미리보기를 재배치하고 본문을 스크롤.
- 단축키: Ctrl+Enter 저장 시작, F6 기록 보기, Ctrl+, 저장 설정. 기록 창에서는 Ctrl+F 검색, Enter 파일 열기.

## 발견해 고친 오류

- 중첩 프레임 안에서 메인 휠·포커스 이동이 작동하지 않던 문제와 종료 후 남은 바인딩·타이머.
- 설정을 저장해도 다음 실행에 기억하지 못하는 문제. 계정·경로의 미적용 입력은 덮어쓰지 않음.
- 설정 창의 X가 변경 내용을 저장하던 문제. X와 Escape는 취소하고 이전 값으로 복원.
- 설정 편집 중 다른 작업이 미저장 값을 쓰던 문제. 편집이 끝나기 전 다른 저장 작업을 막음.
- 기존 Ctrl+H 단축키가 입력칸의 글자를 지우던 문제. 충돌 없는 F6로 변경.
- 예약 등록에서 로그인 연결·영상 용량·계정·폴더 검증이 빠지던 문제와 기록 이전 순서.
- 작업이 오류로 끝나도 진행률이 100%로 남던 문제와 완료 직후 중단이 완료 상태를 덮어쓰던 문제.
- 과거 로그를 읽을 때 새 로그가 스크롤을 아래로 끌고 가던 문제.
- 확인 창의 기본 ‘아니요’ 무시, 중첩 확인 창의 포커스·모달 상태, 긴 본문의 스크롤바 누락.
- 로그인 상태 문구의 폭 고정, 미리보기 줄바꿈, 큰 글꼴에서 도구 막대·통계·파일 열 잘림.
- 긴 미리보기 안내가 아래에서 오른쪽으로 이동할 때 폭이 커지며 레이아웃이 반복되던 문제. 설명 폭을 제한하고 같은 값은 다시 적용하지 않음.

## 검증 방법

전체 오프라인 회귀 검사와 변경한 GUI 검사, 소스와 배포본 자체 점검을 실행합니다. 배포 점검은 ZIP을 프로젝트와 분리된 한글 경로에 풀어 실행하며 GIF 변환·사진/영상 미리보기·출처/작성자 기록·중복 통계·기록 이전·worker 실행을 확인합니다. ZIP CRC, SHA256, 앱과 소스 파일 일치 및 개인 DB·인증정보 미포함도 확인합니다.

화면 검토는 `tools/ui_qa.py`가 만든 임시 계정·미디어 168개·실행 기록 112개를 사용합니다. 기본 45개 화면 상태와 큰 글꼴 14개 상태를 라이트·다크로 캡처하여 확인합니다. X 요청, 실제 로그인 저장, 예약 변경과 다운로드 실행은 차단합니다. 이번 UI 검증은 실제 계정의 새 다운로드를 포함하지 않습니다.

설정과 기록 저장 위치·기존 기록·다운로드 정책은 유지합니다. 사용자의 원본 사진·영상·설정·DB를 변경하지 않습니다. 배포 ZIP 안의 앱 폴더에서 exe를 실행하며 `_internal`을 함께 보관해야 합니다.
