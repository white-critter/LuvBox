XlikeSaver 2.5.0 사용 안내

파일 삭제와 사라진 파일
파일은 탐색기 등 프로그램 밖에서 삭제합니다. 일반 파일 삭제 버튼과 메뉴는 없습니다.
삭제·이동한 뒤 '기록 · 통계 → 새로고침'을 누르면 목록·용량·통계에 반영됩니다.
'사라진 파일'에서 골라 '다시 받기' 또는 '다시 받지 않기'를 누릅니다.
일반 저장은 완료 기록을 유지하므로, 지운 파일을 자동으로 다시 받지 않습니다.
외부에서 원래 경로로 복원한 파일은 새로고침하면 다시 나타납니다.
이전 버전의 삭제 기록은 '이전 삭제 기록'에서 조회할 수 있습니다.
GIF 변환이 성공하면 원본 MP4를 휴지통으로 옮기고 GIF 경로를 기록합니다.
GIF 파일을 외부에서 지우면 새로고침 후 '사라진 파일'에 나타납니다.

1. XlikeSaver-2.5.0 폴더 안의 XlikeSaver-2.5.0.exe를 실행합니다. 폴더째 보관하세요.
2. 본인 X 아이디와 저장 경로를 입력합니다.
3. 로그인 연결 → Edge에서 X 로그인을 누르고 열린 창에서 본인 계정에 로그인합니다.
   연결이 안 되면 '토큰 직접 입력'을 펼치거나 cookies.txt를 사용하세요.
4. 저장 시작을 누릅니다. 중단 후에도 완료한 파일은 기억합니다.
5. 기록 · 통계에서 저장 내역을 보고 트윗 열기로 출처를 확인합니다.

저장 설정은 저장 위치·미디어·확인 방식으로 나뉘며, 설정 저장 또는 취소로 닫습니다.
메뉴의 다크 테마 / 라이트 테마로 화면을 바꿀 수 있습니다.
Ctrl+Enter는 저장 시작, F6는 기록 보기, Ctrl+,는 저장 설정입니다.
기록 창에서 Ctrl+F로 검색하고 Enter로 선택한 파일을 엽니다.
작은 화면이나 큰 글꼴에서는 메인·기록 창을 아래로 스크롤할 수 있습니다.
시험 저장은 한 번 실행한 뒤 자동으로 꺼집니다.
기록 창은 페이지 번호 버튼 또는 처음·이전·다음·마지막으로 이동합니다.
목록에서 Ctrl+Page Up/Down은 이전·다음, Ctrl+Home/End는 처음·마지막 페이지입니다.
한 페이지에 50·100·200개씩 볼 수 있습니다.
통계에서 모든 작성자를 검색하고 클릭하면 대표 이미지가 보입니다.
대표 이미지를 두 번 클릭하면 파일을 엽니다.
긴 경로는 아래 상세 영역에서 스크롤·복사할 수 있습니다.
Pretendard 글꼴이 포함되어 따로 설치할 필요가 없습니다.

파일 메타데이터에 트윗 주소와 작성자 @아이디·프로필 주소를 기록합니다.
숫자 사용자 ID가 제공되면 함께 저장합니다. 영상·GIF도 적용됩니다.
이미 저장된 파일의 작성자는 기록 · 통계 → 파일 관리 → 파일에 출처·작성자 기록으로 넣습니다.
저장 실행 중에는 기존 파일을 작성자만 위해 다시 쓰지 않습니다.
작성자 정보가 기록에 없는 파일은 출처만 저장하며 X에 추가 요청하지 않습니다.

기본값: 구분 없이 저장 / 계정별 폴더 끔 / 새 Like만 빠르게 확인.
빠른 확인은 이미 저장한 파일이 100개 연속 나오면 멈춥니다.
직전 실행이 중단·오류로 끝났거나 미디어 설정을 바꾸면 자동으로 전체를 확인합니다.
파일은 선택한 저장 경로에 바로 저장됩니다.
기록은 이 PC(앱 데이터)에 두고, 저장할 때마다 저장 경로의 .xlikesaver/계정명에 사본을 둡니다.
다른 PC나 새로 설치한 앱은 그 사본에서 기록을 자동으로 가져옵니다.
앱에서 저장 경로를 바꾸면 기록을 자동으로 복사해 이어서 사용합니다.
기존 사진·영상은 원래 위치에 둡니다. 새 파일만 새 위치에 저장합니다.
직접 입력한 경로는 Enter 또는 저장 시작·기록 보기를 누르면 적용됩니다.
이전 폴더가 연결되지 않았으면 새로 시작할지 확인합니다. 중복 저장될 수 있습니다.
이전 폴더를 다시 연결해 앱에서 선택하면 기록을 합칠 수 있습니다.
기록 이전에 실패하면 이전 경로를 유지합니다. 기록 폴더를 지우지 마세요.
동영상은 최고 비트레이트 MP4로, 새 GIF 트윗은 PC에서 GIF로 변환해 저장합니다.
저장 설정에서 'GIF 저장 형식'을 원본 MP4로 바꾸거나 'GIF 크기'를 줄일 수 있습니다.
이미 저장된 MP4는 그대로 남습니다. GIF는 색상 수가 줄고 용량이 커질 수 있습니다.
개별 영상 용량 제한은 기본 200MiB, 0은 제한 없음입니다.

토큰과 쿠키는 로그인 인증정보입니다. 타인에게 보내지 마세요.
제한·오류가 나면 안내를 확인하고 나중에 수동으로 다시 시작합니다.
매일 자동 저장: 메인 화면 '자동 저장'에서 시각을 고르고 '예약 켜기'.
PC가 꺼져 있었으면 다음에 켰을 때 실행하고, 실패하면 알림 창이 뜹니다.
결과는 '자동 저장 → 실행 기록'에서 확인합니다.
요청 간격과 중단 기능이 계정 제한을 예방한다고 보장하지 않습니다.

실행에는 앱 폴더의 exe와 _internal 폴더가 함께 필요합니다. 재배포 시 source와 라이선스도 제공하세요.
개발 환경과 자세한 설명: source/README.md

상단에서 다크 테마 / 라이트 테마를 바꿀 수 있으며 선택을 기억합니다.
기록에서 파일을 클릭하면 썸네일을 봅니다. 동영상·GIF는 첫 장면을 보여 줍니다.
기록은 저장한 순·Like한 순·게시일 순으로 정렬하고 게시일·저장일 기간으로 거를 수 있습니다.
X는 Like한 시각을 알려 주지 않아, 앱이 처음 발견한 시기로 'Like한 시기'를 표시합니다.
검색칸에서 트윗 본문과 #해시태그도 찾습니다. '이 작성자만 보기'로 한 사람 것만 봅니다.
'모아보기'는 섬네일 격자, '통계' 탭은 작성자 순위와 달마다 개수 그래프입니다.
기록 DB가 손상되면 기록 화면의 '기록 복구'를 누르세요. 원본은 먼저 보관합니다.
기록은 저장할 때마다 이 PC에 하루 하나씩 7일 치 백업합니다.
예전에 MP4로 받은 GIF는 기록 화면의 'MP4 GIF를 GIF로'로 바꿉니다. 원본 MP4는 휴지통으로 갑니다.
파일 작업 로그에는 작성자 아이디와 트윗 게시일이 함께 표시됩니다.
GIF 변환 중 중단되면 받은 임시 파일을 남겨 다음 실행에서 변환을 다시 시도합니다.
변환에 실패하거나 GIF가 용량 제한을 넘으면 원본 MP4로 저장하고 계속합니다.

통계의 현재 파일은 해당 계정의 실제 파일 수입니다. 같은 파일의 중복 기록은 한 번만 셉니다.
삭제·이동한 뒤에는 기록 창에서 새로고침을 누르세요. 기록된 트윗 수는 과거 기록 전체입니다.

저장한 뒤 지워진 파일은 기록 화면의 '사라진 파일' 탭에 모입니다.
일부러 지운 파일은 '다시 받지 않기'로 숨기면 앞으로도 받지 않습니다. '숨긴 파일도 보기'에서 되돌립니다.
실수로 사라진 파일은 골라서 '다시 받기'를 누릅니다. 트윗마다 X 요청을 1번씩 10초 간격으로 보냅니다.
삭제·비공개된 트윗의 파일은 받을 수 없으며 목록에 남습니다.
사라진 파일은 페이지로 표시합니다. '이 페이지 모두 선택'은 현재 페이지에만 적용됩니다.
저장 중에는 숨김을 바꿀 수 없습니다. 숨김 선택은 바로 이 PC와 저장 폴더의 기록 사본에 저장됩니다.
아이디나 저장 폴더를 바꿨다면 라이브러리를 새로고침한 뒤 다시 골라 주세요.

기록 · 통계의 항목을 우클릭하면 파일·트윗 열기, 작성자 파일 보기, 경로 복사 등 해당 항목의 기능을 사용할 수 있습니다.
선택된 파일을 우클릭하면 여러 개 선택을 유지합니다. 새 항목을 우클릭하면 그 항목을 선택합니다.
Edge 로그인에서 빈 화면이 나타나면 약 10초 뒤 한 번 자동으로 다시 불러옵니다.
