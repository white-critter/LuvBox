러브박스 (LuvBox) 1.9.4

좋아요한 사진과 영상을 내 폴더에 저장하고 갤러리에서 보는 Windows 앱입니다.

실행

LuvBox.exe를 실행하세요. 압축을 풀 필요가 없고, 이 파일 하나만 있으면 됩니다.
새 버전을 처음 실행할 때 한 번만 앱을 이 PC에 풀어 둡니다. 시작 화면이 진행 상황을 보여 주고, 다음부터는 바로 열립니다.
풀어 둔 앱은 사용자 폴더의 AppData\Local\LuvBox\app에 있으며, 지금 버전과 바로 이전 버전만 남깁니다.
앱은 저장 화면에서 시작합니다.

저장

1. X 연결에서 사용할 Chrome·Edge·Firefox를 선택하고 X 계정 연결을 누르세요.
   선택한 브라우저로 설치 안내·X 열기·연결을 진행합니다. 열린 일반 프로필에 확장을 설치하고 X에 로그인하세요.
   설치 도움말은 접혀 있습니다. 처음 연결하거나 확장 응답이 없나요?를 누르면 펼칩니다.
   약 8초간 응답이 없을 때도 도움말을 펼칩니다. 미설치 확정은 아니므로 브라우저·프로필·확장 활성 상태를 확인하세요.
   Chrome·Edge 확장은 처음 한 번 직접 설치합니다. 표시된 경로를 폴더 창 주소창에 붙여 넣으세요.
   ‘문서’ 폴더가 아니라 manifest.json이 보이는 폴더를 고릅니다. Firefox는 firefox 폴더의 manifest.json을 임시 부가 기능으로 불러옵니다.
   앱과 확장의 코드가 같음을 체크하면 계정을 자동 확인합니다. 브라우저의 @아이디 연결, 앱의 이 계정 연결 승인을 눌러 완료하세요.
   X 로그인·추가 인증을 마쳤거나 계정을 전환했다면 확장의 계정 다시 확인을 누르세요. 연결과 앱 승인은 각각 최대 180초 대기합니다.
   토큰 입력은 고급 연결에 있습니다. 토큰 보관 후에도 창은 열려 있으며 실제 인증을 확인한 것은 아닙니다.
   토큰을 직접 입력했다면 연결창을 닫고 저장 화면에서 본인 X 아이디도 확인하세요.
2. 저장 위치를 고르고 저장 시작을 누르세요.
3. 중단을 누르면 진행 중인 작업을 정리합니다. 이미 저장한 파일은 유지됩니다.
4. 저장 기록 DB가 손상됐다는 안내와 기록 복구 버튼이 나오면 버튼을 눌러 기록을 다시 만드세요.
   손상된 파일은 먼저 이 PC에 백업하며 사진·영상과 중복 방지 기록은 건드리지 않습니다.

토큰·쿠키는 비밀번호처럼 보관하고 다른 사람에게 보내지 마세요.
토큰을 보관했다는 안내는 X가 로그인을 확인했다는 뜻이 아닙니다.
저장 화면에서 자세히 보기를 켜면 최근 저장한 파일과 작성자·본문·게시 시각을 확인합니다.
GIF와 동영상은 첫 장면을 정지 사진으로 표시하며, 자세히 보기를 끄면 숨깁니다.
연결 정보는 이 Windows 사용자 계정에 암호화해 보관합니다.
브라우저 확장의 스토어 배포·자동 설치는 제공하지 않습니다.
브라우저 계정 확인됨과 X 목록 접근 확인됨은 다릅니다. 실제 목록 접근은 저장 중 확인합니다.
다시 연결 필요가 나오면 X 연결에서 재연결하세요. 저장한 연결·사진·기록은 자동으로 지우지 않습니다.
통신 장애나 요청 제한으로 무조건 다시 로그인할 필요는 없습니다.

저장 옵션

설정에서 사진·영상·GIF, 폴더 정리, GIF 크기와 용량 제한 등을 바꿉니다.
저장 전에 하나씩 확인을 켜면 미리보기를 보고 저장·건너뛰기·저장 안 함을 고를 수 있습니다.
건너뛴 항목은 다음 저장에서 다시 나올 수 있습니다. 저장 안 함으로 고른 항목은 기록에 남겨 제외합니다.
저장 확인창을 닫으면 전체 저장 작업을 중단합니다.

새 파일명은 작성자ID_게시물ID_번호 형식입니다. 기존 파일명도 계속 인식합니다.
원래 파일을 앱 업데이트 때문에 이동하거나 이름을 바꾸지 않습니다.
설정 저장에 실패했다는 안내가 나오면 오류를 확인하고 다시 설정하세요.

갤러리

사진을 이어서 스크롤하고 검색·정렬할 수 있습니다. 위쪽 첫 줄에 검색과 정렬·종류·크기가, 둘째 줄에 빠른 필터(즐겨찾기, 중복 사진, AI 분류, 작성자, 해시태그, 내 태그, 날짜)가 있습니다.
작성자·해시태그·내 태그는 목록에서 고르고, 날짜를 누르면 옆에 펼쳐지는 달력으로 게시일 또는 저장일 범위를 고릅니다. 고르는 즉시 적용되고, 켜진 필터는 붉게 표시됩니다. × 필터 지우기는 걸린 필터가 있을 때만 나옵니다.
필터 아래 한 줄에 사진 수와 적용된 필터가, 그 오른쪽에 가장 최근 안내와 진행 막대가 나옵니다.
상단의 AI 분류를 누르면 분류별 사진 수가 나오고, 분류를 고르면 그 사진만 봅니다. 같은 메뉴의 AI 자동분류 실행을 누르면 로컬 AI(CLIP) 모델로 사진을 #일러스트, #인물, #동물, #짤·텍스트, #풍경·배경으로 자동 분류합니다. 진행 건수는 사진 묶음이 끝날 때마다 바뀌고, 확인 중에는 막대가 움직입니다. 분류가 중간에 실패하면 그 사진은 분류된 것으로 남지 않으며, 다시 실행하면 남은 사진부터 이어집니다. 파일을 열 수 없으면 그 파일의 크기나 수정 시각이 바뀌기 전까지는 다시 열지 않습니다. 잠긴 파일은 다음 실행에서 다시 시도합니다. AI 태그만 지운 사진은 저장된 특징값으로 다시 분류하며, 이때는 모델을 다시 돌리지 않습니다. 직접 뺀 사진과 가르쳐 둔 분류는 유지됩니다. 여러 장을 가르치면 저장 건수가 함께 올라갑니다. AI 태그 초기화는 확인 후에만 실행되고, 직접 추가한 태그는 유지됩니다. 자동분류·초기화·가르치기 중에는 태그를 바꾸거나 휴지통으로 옮길 수 없습니다.
제목 줄의 통계 버튼으로 전체 미디어 수, 저장 용량, 상위 작성자 TOP 10과 월별 저장 추이를 확인합니다. 불러오지 못하면 이유와 다시 시도 버튼이 나옵니다.
마음에 드는 사진과 영상은 우측 상단 ★ 버튼이나 단축키 F로 즐겨찾기에 추가할 수 있으며, 상단 ★ 즐겨찾기 버튼으로 모아볼 수 있습니다.
중복 사진 버튼을 누르면 같은 사진을 묶음으로 보여 주는 화면이 열립니다. 중복 검사는 내용이 완전히 같은 파일만 찾습니다. 화질만 다른 사진 포함을 켜고 검사하면 크기·화질만 다르게 저장된 같은 사진도 찾으며, 두 사진의 화면을 직접 비교해 99% 이상 같을 때만 묶습니다. 묶음마다 남길 한 장에는 남김, 나머지에는 사본이라고 표시합니다. 묶음의 사본 선택을 누르거나 사진을 눌러 고른 뒤 휴지통으로 보내세요. 검사 중단을 누르면 현재 파일 확인이 끝난 뒤 멈춥니다. 이미 저장된 유효한 해시는 다음 검사에서 재사용하고, 수정된 사진은 다시 확인합니다.
사본 일괄 선택은 마지막 검사의 묶음마다 즐겨찾기를 우선하고 파일 크기가 큰 순서로 1장씩 남깁니다. 현재 목록에 불러온 사본만 고르며 기존 선택과 합쳐 최대 2,000개입니다. 파일 크기가 곧 화질을 뜻하지는 않으므로 휴지통 이동 전 선택한 사진을 확인하세요. 중복 보기에서 보내는 파일은 옮기기 직전에 같은 내용의 다른 파일이 남아 있는지 다시 확인하고, 확인되지 않으면 그대로 둡니다. 묶음을 통째로 골라도 한 장은 남습니다. 아직 검사하지 않았거나 폴더를 합쳤다면 먼저 중복 검사를 실행하세요.
작성자 목록의 ‘미디어 N개’는 그 작성자의 저장된 사진·영상·GIF 수입니다.
여러 개 선택을 누르고 파일을 고른 뒤 휴지통으로 이동할 수 있습니다. 고른 파일에 쓰는 동작은 창 아래 막대에 있고, 선택 끝내기나 Esc로 마칩니다. Shift를 누르고 사진을 누르면 마지막으로 누른 사진부터 거기까지 선택되고, 마우스로 끌면 사각형에 닿은 사진이 선택됩니다(Ctrl을 누르고 끌면 기존 선택에 추가). 저장 중에도 고를 수 있고, 휴지통 이동은 작업이 끝난 뒤 가능합니다. 현재 목록 선택은 이미 불러온 항목만 선택합니다.
휴지통으로 옮긴 뒤에도 갤러리는 보던 위치에 그대로 있고, 옮긴 사진만 목록에서 빠집니다. 옮기지 못한 파일이 있거나 중복 사진만 보는 중이면 목록을 다시 읽습니다.
미리보기에서 Delete 키나 휴지통으로를 눌러 옮기면 다음 사진의 미리보기로 돌아옵니다. 확인창에서 취소하면 보던 사진으로 돌아옵니다.
확인창에서 다음 저장 때 다시 받지 않을지도 고릅니다. 파일이 바뀌었거나 확인할 수 없으면 다시 선택해야 합니다.
목록의 썸네일 크기는 작게·보통·크게 중에서 고릅니다. 고른 크기는 다음 실행에도 유지됩니다.
사진을 선택하면 미리보기에서 원본 파일·폴더·원문을 열 수 있습니다.
미리보기의 + / − 또는 마우스 휠로 확대·축소하고, 확대된 사진을 드래그해 이동하세요.
소리가 있는 영상은 기본 음소거이며 소리 켜기 / 끄기로 조절합니다. 다른 파일을 열거나 닫으면 다시 음소거됩니다.
화면 맞춤으로 돌아올 수 있으며, 확인된 1,600만 화소 이하 사진은 원본 100%를 지원합니다.
이전 / 다음 버튼이나 좌우 방향키로 현재 검색·정렬 순서의 사진을 탐색합니다.
미리보기와 저장 전 확인창은 앱 창을 넓게 사용합니다. 사진은 비율을 유지해 표시합니다.
창 최대화를 누르면 앱 전체가 최대화되며 미리보기도 함께 커집니다. 창 복원으로 돌아옵니다.
갤러리 게시물 본문은 기본으로 접혀 있으며 본문 보기·본문 접기로 펼치고 접습니다.
새로고침 버튼이 새 사진 보기로 바뀌면 눌러 새로 저장한 항목을 반영하세요.
AI 자동분류, 중복 검사, 분류 가르치기가 끝나도 보던 위치와 열어 둔 미리보기는 그대로입니다. AI 분류 필터나 중복 사진 보기를 켜 둔 때만 결과에 맞춰 목록을 다시 읽습니다.
파일을 다른 곳에서 옮기거나 삭제했다면 파일 없음 안내가 나올 수 있습니다.

단축키

제목 줄의 단축키 버튼이나 F1 키로 같은 목록을 앱에서 볼 수 있습니다.
갤러리: Ctrl+F 검색, Enter·Space 미리보기(여러 개 선택 중에는 선택·해제), 방향키 이동, F 즐겨찾기, B 즐겨찾기만 보기, D 중복 사진만 보기,
        S 통계, Ctrl+A 불러온 항목 모두 선택, Ctrl+클릭 선택에 추가·제외, Shift+클릭 범위 선택, 끌어서 사각형 선택,
        Delete 휴지통으로, Esc 선택 해제·검색어 지우기, F5 새로고침. 휠은 계속 굴리면 빨라집니다.
미리보기: ←·→ 이전·다음, F 즐겨찾기, +·− 확대·축소, 0 화면 맞춤, 1 원본 100%, M 영상 소리, Delete 휴지통으로, Esc 닫기.
검색란에 입력 중이거나 작성자·정렬 같은 목록을 고르는 중에는 글자 키가 단축키로 동작하지 않습니다.

앱 창은 마지막으로 닫을 때의 크기와 위치로 다시 열립니다.

업데이트

새 버전이 나오면 저장·갤러리 화면 위에 알림과 변경 사항이 나옵니다. 업데이트를 누르면 릴리스의 서명을 확인하고 새 LuvBox.exe를 받아 확인한 뒤 지금 파일과 바꿔 둡니다. 서명을 확인하지 못한 릴리스는 받지 않습니다.
받는 동안에도, 받은 뒤에도 하던 일은 계속할 수 있습니다. 지금 다시 시작을 누르거나 다음에 열 때 새 버전으로 열립니다.
새 버전 확인은 시작할 때 하루에 한 번 합니다. 설정의 업데이트에서 끄거나 지금 확인을 누를 수 있습니다.
확인할 때 이 PC나 계정에 관한 것은 보내지 않습니다. 설정·로그인·기록은 그대로 이어집니다.
자동 저장 예약은 그대로 쓸 수 있습니다. LuvBox.exe를 다른 폴더로 옮겼다면 설정 → 고급 → 자동 저장 설정에서 현재 버전으로 변경하세요.
1.7.x 이하에서는 최신 LuvBox.exe를 한 번 직접 받아야 합니다(1.8.0부터는 앱 안에서 받습니다). 이전 버전 폴더와 ZIP은 지워도 되고, 예약이 있었다면 위 메뉴에서 한 번 현재 버전으로 변경하세요.
작업 표시줄에 두려면 실행 중인 LuvBox 창의 아이콘을 고정하세요.
지우려면 LuvBox.exe와 AppData\Local\LuvBox\app 폴더를 지우세요. 같은 LuvBox 폴더의 나머지에는 설정·로그인·기록이 있습니다.
1.1.5 이하 폴더에서 불러온 브라우저 확장은 연결창의 폴더 경로로 한 번 다시 불러와 주세요.
새 연결 단계 표시를 쓰려면 X 연결을 한 번 연 뒤 확장 관리에서 새로고침해 확장을 1.1.0으로 갱신하세요.
이전 1.0.0 확장도 계정을 전달할 수 있지만 중간 단계 표시는 없습니다. 저장한 계정은 다시 연결할 필요가 없습니다.
Firefox 임시 확장은 브라우저를 다시 시작하면 다시 불러와야 합니다.
코드 서명이 없어 Windows가 경고할 수 있습니다. 릴리스의 SHA256 파일과 LuvBox.exe의 해시를 비교한 뒤 실행하세요.

설정 → 고급

자동 저장 설정에서 매일 실행 시각을 정하고 예약을 만들거나 변경·해제합니다. 저장 화면의 자동 저장 설정 버튼으로도 열 수 있습니다.
예약은 하나이며 실행 시 저장된 계정·폴더·옵션을 사용합니다. 계정이나 폴더를 바꾸면 다음 대상도 바뀝니다.
예약 해제는 다음 실행만 막으며 이미 시작한 저장과 받은 파일은 유지합니다.
실행 기록은 모든 계정의 수동·자동 저장 결과를 최신순으로 보여줍니다. 각 줄에 계정과 저장·이미 저장됨·저장 못 함 개수가 나옵니다.
최근 결과 1,000건까지 보관하며, 남아 있지 않은 오래된 예약 결과를 추정하지 않습니다.
저장 못 한 미디어는 저장에 실패했거나 크기 제한을 넘어 건너뛴 사진·영상·GIF를 이유와 함께 보여줍니다.
다시 저장으로 그 미디어만 다시 받을 수 있고, 크기 초과는 설정에서 제한을 올린 뒤 다시 저장할 수 있습니다.
이 목록은 계정과 저장 폴더마다 최근 500건입니다. 목록에서 지워도 저장한 파일에는 영향이 없고, 직접 제외한 항목은 빠지지 않습니다.
저장하지 못한 미디어는 저장할 때 작은 미리보기 한 장을 X의 이미지 서버에서 받아 이 PC에 보관합니다(영상은 대표 장면). 미리보기가 비어 있는 항목은 전체 목록 다시 확인으로 저장하면 그때 채워집니다. 받지 못한 항목은 원문 보기로 확인하세요.
직접 제외 탭은 저장 폴더의 기록에 남은 제외 항목입니다. 저장 확인에서 저장 안 함으로 골랐거나, 지울 때 다시 받지 않기로 한 미디어가 나오며 실패로 세지 않습니다.
제외 해제는 다음 저장에서 다시 받게 하고, 다시 받기는 지금 받습니다. 저장 폴더를 바꿔도 그 폴더의 기록에서 다시 볼 수 있습니다.
이미 저장했거나 중복이라 건너뛴 미디어는 목록에 쌓이지 않고, 나중에 저장되면 목록에서 자동으로 사라집니다.
휴지통에서 원본 파일을 복원하려면 Windows 휴지통을 사용하세요. 다음 저장 때 복원된 파일을 다시 확인합니다.
