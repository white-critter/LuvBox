러브박스 (LuvBox) 1.1.2 — 개발 버전

좋아요한 사진을 쉽게 저장하고 보는 Windows 앱입니다.
Qt 화면으로 전환 중인 개발 버전이며 정식 공개 배포 완료판은 아닙니다.

실행

ZIP 전체를 푼 뒤 LuvBox-1.1.2 폴더의 LuvBox-1.1.2.exe를 실행하세요.
같은 폴더의 _internal을 함께 보관하세요. EXE만 옮기면 실행되지 않습니다.

저장

1. X 연결: 브라우저 연결(확장) 또는 토큰 입력 중 하나를 선택하세요.
   브라우저 연결의 확장 관리 열기·폴더 경로 복사로 처음 한 번 설치한 뒤 코드·계정을 확인해 승인합니다.
   토큰 방식은 저장 화면에서 X 아이디도 입력하세요.
2. 저장 위치를 고르고 저장 시작을 누르세요.
3. 중단해도 이미 저장한 파일은 유지됩니다.

브라우저 확장의 간편 설치·스토어 배포는 아직 제공하지 않습니다.
토큰·쿠키는 비밀번호처럼 보관하고 다른 사람에게 보내지 마세요.
별도 Chrome 창의 새 로그인은 제공하지 않습니다.

갤러리

페이지 버튼 없이 이어서 스크롤합니다. 미리보기는 작게·보통·크게로 바꿉니다.
사진을 선택해 미리보기를 열면 파일·폴더·원문을 열 수 있습니다.
새로 저장한 사진이 있으면 새 사진 보기를 누르세요.

설정

저장 옵션은 설정에, 드물게 쓰는 옵션은 고급 하나에 있습니다.
테마는 블랙·레드 하나입니다. CSV·통계·일괄 파일 관리 메뉴는 없습니다.
새 파일명은 작성자ID_게시물ID_번호 형식입니다. 기존 이름도 계속 인식합니다.
기존 자동 저장 예약이 있다면 설정 → 고급에서 확인·해제하거나 현재 버전으로 변경합니다.
예약 해제는 다음 실행만 막고 진행 중인 저장과 받은 파일은 그대로 둡니다.
실제 EXE의 시작·갤러리·사진 미리보기·설정·연결창·종료를 격리 확인합니다.
실제 X 인증·다운로드·예약 변경은 별도입니다. 소스·라이선스는 ZIP에 함께 있습니다.
