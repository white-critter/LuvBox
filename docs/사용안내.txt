러브박스 (LuvBox) 1.0.0 사용 안내

X(트위터)에서 내가 좋아요(Like) 누른 게시물의 사진·동영상·GIF를 내 PC 폴더에 모아 두는 프로그램입니다.


실행하기

1. LuvBox-1.0.0 폴더 안의 LuvBox-1.0.0.exe를 실행합니다.
   exe는 같은 폴더의 _internal과 함께 있어야 합니다. 옮길 때는 폴더째 옮기세요.
2. 처음 실행할 때 Windows가 "PC 보호" 창을 띄우면 "추가 정보 → 실행"을 누릅니다.

Windows 10·11에서 사용할 수 있습니다. 기본 브라우저의 X 로그인을 쓰려면 연결 확장을 처음 한 번 설치합니다.
확장을 설치하기 어렵다면 Microsoft Edge의 별도 로그인 창을 사용할 수 있습니다.


처음 시작하기

1. '로그인 연결 → 연결 확장 설치 안내'에서 기본 브라우저에 맞는 확장을 설치합니다.
2. '기본 브라우저 계정 연결'을 누르고 앱과 확장의 연결 코드가 같은지 확인한 뒤 계정을 연결합니다.
   계정 아이디는 자동으로 입력됩니다. 다른 계정은 '계정 추가'로 연결하고 X 계정 목록에서 선택합니다.
   확장 설치가 어려우면 'Edge에서 X 로그인'을 사용합니다. 기존 토큰·쿠키 파일 연결도 계속 쓸 수 있습니다.
3. 저장 폴더를 고르고 '저장 시작'을 누릅니다.

확장 설치 방법과 Firefox 임시 설치의 제한은 함께 담긴 source/assets/browser-extension/README.md에 있습니다.

한 번 받은 파일은 건너뛰고, 다음부터는 새로 누른 좋아요만 받습니다.
중간에 멈추거나 오류가 나도 이미 받은 파일은 그대로 남습니다.


저장 설정

- 폴더 정리: 한 폴더에 모두, 작성자별, 저장한 날짜별 중에서 고릅니다.
- 동영상·GIF를 받을지와 영상 하나의 최대 크기(기본 200MB)를 정합니다.
- 평소에는 '새 Like만 확인', 예전 좋아요까지 다시 보려면 '전체 목록 다시 확인'을 고릅니다.


보고 골라 저장하기

- 메인 화면의 '저장 전에 하나씩 확인'을 켜고 '저장 시작'을 누릅니다. 기본은 꺼짐이며 다음 실행에도 기억합니다.
- 사진은 크게, 동영상·GIF는 소리 없이 처음 30초를 반복해 보여줍니다.
- '저장', '이번엔 건너뛰기', '저장 안 함', '전체 작업 중단'을 선택합니다. 창을 닫아도 전체 작업을 중단합니다.
- 저장 중에도 옵션을 켜고 끌 수 있습니다. 확인창의 '이후 자동 저장'을 누르면 지금 파일부터 자동으로 저장합니다.
- 미리보기를 위해 저장 폴더에 임시 파일을 먼저 받으므로 인터넷 데이터가 사용됩니다. 동기화 폴더에서는 임시 파일도 동기화될 수 있습니다.
- '저장'을 눌러 보관한 파일만 성공 기록에 추가합니다. 이미 받은 파일은 확인창 없이 건너뜁니다.
- 건너뛴 새 파일은 다음 실행에서 다시 확인합니다. 다음 '새 Like만 확인'은 건너뛴 파일이 나올 때까지만 조금 더 확인합니다.
  '사라진 파일 → 다시 받기'에서 건너뛴 파일은 필요하면 다시 받기로 다시 선택하세요.
- 건너뛰기는 이번 실행에만 적용됩니다. 이후 확인 옵션을 끄거나 예약 자동 저장을 실행하면 건너뛴 새 파일도 자동으로 저장될 수 있습니다.
- '저장 안 함'을 고른 파일은 다시 묻지 않고 예약 자동 저장에서도 받지 않습니다.
  필요하면 '사라진 파일'에서 '숨긴 파일도 보기'를 켜고 골라 '다시 받기'를 누릅니다.
- 예약 자동 저장은 확인창 없이 진행합니다.


기록 · 통계

- 받은 파일을 목록이나 갤러리로 보고, 작성자·게시물 내용으로 찾습니다.
- 끌어서 여러 개를 고르거나 '여러 개 선택'을 켜고 하나씩 클릭합니다.
- 파일을 고르면 미리보기가 나오고 '파일 열기', '트윗 열기'로 원본을 봅니다.
- 통계에서 작성자를 누르면 그 작성자의 파일이 최근 게시물부터 모두 나옵니다.
  100개씩 보여 주며 '더 보기'로 이어서 봅니다. 여기서도 골라서 휴지통으로 보낼 수 있습니다.
- '폴더 열기'로 저장 폴더를 탐색기에서 엽니다.
- 목록·갤러리에서 파일을 골라 '휴지통으로 보내기'를 누르거나 우클릭 메뉴를 사용합니다.
  확인창에서 개수·용량을 확인합니다. 휴지통을 사용할 수 없는 위치는 건너뜁니다.
  보낸 파일은 '사라진 파일'에서 확인합니다.


파일을 지웠을 때

- 프로그램에서 휴지통으로 보낼 때는 '이 계정에서 다시 받지 않기'가 기본으로 켜져 있습니다.
  다시 필요하면 '사라진 파일'의 '숨긴 파일도 보기'에서 골라 '다시 받기'를 누릅니다.
- Windows 휴지통에서 원래 위치로 복원한 뒤 '새로고침'을 누르면 파일이 다시 표시됩니다.
- 탐색기에서 직접 지운 파일도 기록 창의 '새로고침'으로 '사라진 파일'에 반영됩니다.
- 지운 파일은 자동으로 다시 받지 않습니다. 필요하면 골라서 '다시 받기'를 누릅니다.
- 목록에서 치우려면 '다시 받지 않기'를 누릅니다. '전체 선택'으로 모든 페이지를 고릅니다.
- 파일을 고르면 작은 미리보기, 원래 폴더, 사라진 것을 안 날짜가 보입니다.
  새 파일의 작은 미리보기는 다운로드해 저장할 때 자동으로 남깁니다. 기존 파일도 열어볼 때 보완합니다.
  미리보기가 없는 이전 파일을 한꺼번에 보완할 때만 '파일 관리 → 이전 파일 미리보기 보완'을 사용합니다.
- 저장 폴더를 옮겼거나 외장 드라이브를 뺐다면 기록 창이 알려 줍니다.
  옮긴 경우 메인 화면의 '저장 폴더'에서 새 위치를 고릅니다.


매일 자동 저장

'자동 저장'에서 시각을 고르고 '예약 켜기'를 누릅니다.
매일 그 시각에 새 좋아요를 저장하고, PC가 꺼져 있던 날은 다음에 켤 때 저장합니다.
실패하면 알림으로 알려 줍니다. 기본 브라우저나 Edge로 연결한 계정을 사용할 수 있습니다.


여러 계정

'계정 추가'로 다른 계정을 연결하면 아이디가 자동으로 목록에 추가됩니다.
X 계정 목록에서 계정을 고르면 해당 계정의 로그인 연결과 기억해 둔 저장 폴더를 사용합니다.
선택한 계정 연결을 해제해도 다른 연결 계정은 유지됩니다.

계정마다 기록을 따로 둡니다. 여러 계정이 한 저장 폴더를 함께 쓰면 기록 창이 알려 주고,
'기록 합치기'로 다른 계정이 받은 파일도 지금 계정에서 함께 관리할 수 있습니다.

꼭 알아 두세요

- X의 공식 기능이 아닙니다. 천천히 요청하지만 계정이 제한될 가능성을 없앨 수는 없습니다.
- '요청 한도' 안내가 나오면 알려 준 시각 이후에 다시 시작하세요.
- 저장한 사진·영상의 저작권은 원작자에게 있습니다. 개인 보관 용도로만 쓰세요.
- 로그인 정보는 이 PC에만 암호화해 보관합니다. 토큰이나 cookies.txt를 다른 사람에게 보내지 마세요.
