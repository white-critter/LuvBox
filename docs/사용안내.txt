러브박스 (LuvBox) 1.1.6

좋아요한 사진과 영상을 내 폴더에 저장하고 갤러리에서 보는 Windows 앱입니다.

실행

ZIP 전체를 푼 뒤 LuvBox-1.1.6 폴더의 LuvBox-1.1.6.exe를 실행하세요.
같은 폴더의 _internal을 함께 보관하세요. EXE만 옮기면 실행되지 않습니다.
앱은 저장 화면에서 시작합니다.

저장

1. X 연결에서 브라우저 연결(확장) 또는 토큰 입력을 선택하세요.
   확장은 처음 한 번 직접 설치합니다. 앱의 설치 안내에서 확장 관리 주소와 폴더 경로를 복사할 수 있습니다.
   브라우저 연결은 앱·확장의 연결 코드와 계정을 확인한 뒤 승인하세요.
   토큰을 직접 입력했다면 저장 화면에서 본인 X 아이디도 확인하세요.
2. 저장 위치를 고르고 저장 시작을 누르세요.
3. 중단을 누르면 진행 중인 작업을 정리합니다. 이미 저장한 파일은 유지됩니다.
4. 저장 기록 DB가 손상됐다는 안내와 기록 복구 버튼이 나오면 버튼을 눌러 기록을 다시 만드세요.
   손상된 파일은 먼저 이 PC에 백업하며 사진·영상과 중복 방지 기록은 건드리지 않습니다.

토큰·쿠키는 비밀번호처럼 보관하고 다른 사람에게 보내지 마세요.
토큰을 보관했다는 안내는 X가 로그인을 확인했다는 뜻이 아닙니다.
연결 정보는 이 Windows 사용자 계정에 암호화해 보관합니다.
브라우저 확장의 스토어 배포·자동 설치는 제공하지 않습니다.

저장 옵션

설정에서 사진·영상·GIF, 폴더 정리, GIF 크기와 용량 제한 등을 바꿉니다.
저장 전에 하나씩 확인을 켜면 미리보기를 보고 저장·건너뛰기·저장 안 함을 고를 수 있습니다.
건너뛴 항목은 다음 저장에서 다시 나올 수 있습니다. 저장 안 함으로 고른 항목은 기록에 남겨 제외합니다.
저장 확인창을 닫으면 전체 저장 작업을 중단합니다.

새 파일명은 작성자ID_게시물ID_번호 형식입니다. 기존 파일명도 계속 인식합니다.
원래 파일을 앱 업데이트 때문에 이동하거나 이름을 바꾸지 않습니다.
설정 저장에 실패했다는 안내가 나오면 오류를 확인하고 다시 설정하세요.

갤러리

사진을 이어서 스크롤하고 검색·정렬할 수 있습니다.
미리보기 크기는 작게·보통·크게 중에서 고릅니다.
사진을 선택하면 미리보기에서 원본 파일·폴더·원문을 열 수 있습니다.
새 사진 보기가 나타나면 눌러 새로 저장한 항목을 반영하세요.
파일을 다른 곳에서 옮기거나 삭제했다면 파일 없음 안내가 나올 수 있습니다.

업데이트

새 버전 ZIP을 다른 폴더에 풀어 실행하세요. 설정·로그인·기록은 그대로 이어집니다.
새 버전이 정상 동작하면 이전 버전 폴더는 지워도 됩니다.
자동 저장 예약이 있으면 설정 → 고급에서 현재 버전으로 변경하세요.
1.1.5 이하 폴더에서 불러온 브라우저 확장은 연결창의 폴더 경로로 한 번 다시 불러와 주세요.
코드 서명이 없어 Windows가 경고할 수 있습니다. 릴리스의 SHA256 파일과 ZIP 해시를 비교한 뒤 실행하세요.

고급과 기존 예약

드물게 쓰는 옵션은 설정의 고급 영역에 있습니다.
기존 자동 저장 예약이 있으면 상태를 확인하고 해제하거나 현재 버전으로 연결할 수 있습니다.
예약 해제는 다음 실행만 막으며 이미 시작한 저장과 받은 파일은 유지합니다.
새 예약 생성과 휴지통·복구 화면은 제공하지 않습니다.

기존 설정·로그인·기록·저장 파일은 계속 사용합니다.
테마는 블랙·레드 하나입니다. CSV·통계·일괄 파일 관리 메뉴는 기본 화면에 없습니다.
소스와 라이선스는 배포 ZIP에 함께 있습니다.
검사와 보안 변경의 자세한 내용은 동봉 소스의 docs/verification.md,
docs/comprehensive-review-20261024.md, docs/security-review-20261024.md를 참고하세요.
