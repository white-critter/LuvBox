# 1.11.2 실제 파일 통계 수정

검증일: 2026-10-06. 1.11.1 안정화 작업 위에 적용했습니다. UI 전면 개편과 2.0.0은 다음 작업으로 남깁니다.

## 변경

- 파일 수·사진/영상/GIF 수·용량·파일 메타데이터 개수·작성자 순위·게시월/저장월 통계를 현재 존재하는 파일 기준으로 통일했습니다.
- Windows 경로를 정규화하여 같은 파일 경로는 한 번만 셉니다. 같은 트윗이라도 실제로 다른 경로에 두 벌 남아 있으면 각각 셉니다.
- 삭제되거나 접근할 수 없는 파일은 현재 파일 수에서 제외합니다. 과거 기록·중복 다운로드 방지 DB·Like 순서·트윗 본문은 유지합니다.
- 트윗 수와 게시일 범위는 전체 기록 기준을 유지하며 화면에 **기록된 트윗**이라고 표시합니다. 페이지 합계도 **기록**으로 표시하여 현재 파일 수와 구분합니다.
- 공유 저장 폴더에서 작성자별 파일을 직접 옮긴 경우, 해당 계정에 이미 있는 정확한 트윗/미디어 번호/종류를 확인하여 다시 연결합니다. 작성자와 최초 저장일 등 기존 정보는 유지합니다. 다른 계정의 모르는 파일은 가져오지 않고, 연결이 끊긴 이전 경로는 보존합니다.
- 같은 파일의 오래된 저장 기록보다 최신 X 목록의 작성자 정보가 통계에 우선하도록 보완했습니다.

기록 창은 DB의 중복을 제거한 통계를 먼저 보여 주고 기존 백그라운드 폴더 확인 후 갱신합니다. 페이지를 넘길 때 전체 파일을 다시 검사하지 않습니다. 직접 이동·삭제한 뒤에는 **새로고침**을 누르세요. Like 월별 통계는 파일 수와 별개인 Like 이력을 계속 사용합니다.

## 실제 계정 사본 검증

chobby6911의 DB와 다운로드 기록을 임시 폴더에 복사하여 검사했습니다. 원본 파일·DB·설정은 수정하지 않았으며 X에 요청하지 않았습니다.

| 항목 | 재확인 전 | 재확인 후 |
| --- | ---: | ---: |

재확인으로 기존 작성자별 기록에 있는 파일 3개를 새 위치에 다시 연결했습니다. 원본 DB에는 이 변경을 적용하지 않았으므로 새 버전에서 기록 창을 열거나 새로고침하면 반영됩니다.

게시월 합계는 5,663개로 파일 수와 일치합니다. 작성자별 합계는 작성자를 모르는 파일 1개를 제외한 5,662개, 저장월 합계는 정확한 저장일이 없는 과거 파일을 제외한 5,368개입니다. 날짜와 작성자를 추측해 채우지 않습니다.

실제 파일 검증은 약 0.9초, 캐시 통계 계산은 약 0.11초, 폴더 재확인은 약 3.13초였습니다. 공유 폴더의 파일 재연결은 미리 만든 미디어 식별값 사전으로 조회합니다. 측정 환경에 따라 시간은 달라집니다.

사용자 원본 9,254개 파일·DB·설정의 크기와 수정 시각은 검증 전후 동일했고 설정 내용도 동일했습니다. 숫자와 측정 결과는 `.test-output/stats-1.11.2-real-copy.json`에 남깁니다.

## 회귀 검증

동일 경로 중복, 실제 별도 복사본, 삭제·크기 변경, 작성자 변경, 이동 파일 재연결, 다른 계정 파일 제외, 이전 드라이브 재연결, Like 이력 유지, GUI 통계와 페이징을 확인했습니다. 전체 테스트 총 **479개 중 477개 통과, 2개 생략**(기존 링크 환경 조건 1개, 실제 심볼릭 링크 생성 권한 1개)이며 소스 자체 점검도 통과했습니다. 로그는 `.test-output/stats-1.11.2-tests.log`에 있습니다.
