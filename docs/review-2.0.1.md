# 2.0.1 화면 조정 검증

검증일: 2026-10-06.

## 변경 내용

- 메인 창의 시작 높이를 880px에서 1320px로 늘렸습니다. 작은 화면에서는 화면 높이에서 100px를 남겨 줄이고, 본문 스크롤을 유지합니다. 시작 위치에도 제목 표시줄과 작업 표시줄의 공간을 남깁니다.
- 기록·통계 창의 기본 크기를 1500×1100으로 늘렸습니다. 작은 화면에 맞게 제한하며 Windows 최대화와 크기 조절을 지원합니다.
- 저장 설정의 사각 남색 영역을 카드 색상과 둥근 테두리로 바꿨습니다. 버튼·탭과 같은 곡률에 맞춰 안쪽 여백을 확보했습니다.
- 기록·통계 탭 아래의 중복 여백을 없앴습니다.
- 자동 저장의 ‘예약 켜기·갱신’ 버튼을 다른 버튼과 같은 높이로 맞췄습니다. 선택 색상과 비활성 상태는 유지합니다.

## 검증

임시 설정·미디어·기록을 사용하는 GUI 검사와 라이트·다크 화면 검토를 진행합니다. 기본 창과 최대화, 작은 화면과 큰 글꼴에서 배치를 확인합니다. 실제 사용자 설정·기록·미디어를 변경하지 않으며 X 요청과 실제 예약 등록을 차단합니다.

소스 자체 점검과 배포 ZIP을 별도의 한글 폴더에 풀어 실행하는 자체 점검, ZIP CRC·SHA256·파일 일치 검사를 진행합니다. ZIP에는 기존처럼 exe와 `_internal`이 들어 있는 앱 폴더, 소스와 라이선스를 포함합니다.

## 검증 결과

- GUI·테마 관련 **152종 검사 통과**: 통합 GUI 150종과 별도 테마 27종(이 중 새 테마 검사 2종 포함). 통합 로그 `.test-output/ui201-gui-tests.log`.
- 메인 초기 높이와 작은 화면 제한, 기록 창의 Windows 최대화 버튼·실제 최대화, 탭 버튼과 페이지 사이 실제 간격을 확인했습니다.
- 최종 소스 자체 점검 통과: `.test-output/ui201-source-selftest.json`.
- 화면 검토: 기본 20개, 큰 글꼴 12개, 1366×768 모의 화면 18개를 라이트·다크에서 확인했습니다. 네트워크 요청 0회, 고정 버튼·입력의 잘림과 작업 표시줄 겹침 0개입니다. 결과는 `.test-output/ui2.0.1/{captures,large,short}/manifest.json`에 있습니다.
- 배포 ZIP 점검과 분리 폴더의 exe 자체 점검 결과는 `.test-output/ui201-release-audit.json`과 `.test-output/ui201-frozen-selftest.json`에 기록합니다. 체크섬은 `release/SHA256-2.0.1.txt`에 있습니다.
