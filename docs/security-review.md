# 보안 경계와 검증

현재 제품은 PySide6 + Qt Quick 앱입니다. 이 문서는 지원하는 경계와 검증 방법을 설명합니다. 버전별 변경은 [CHANGELOG](../CHANGELOG.md), 최신 실행 결과는 [검증 기록](verification.md), 연결 절차와 암호화 상세는 [브라우저 연결](browser-login.md)을 참고하세요.

## 계정·설정·요청

- 직접 고른 cookies.txt는 1MB를 넘으면 내용을 해석하기 전에 거절합니다. 검증과 저장 작업이 같은 상한으로 읽습니다.
- 계정 세션은 현재 Windows 사용자의 DPAPI로 암호화합니다. 토큰·쿠키·브라우저 프로필·개인 DB를 일반 설정·로그·Git·배포 ZIP에 넣지 않습니다. 연결 실패·취소는 기존 세션을 초기화하지 않습니다.
- 기존 세션의 읽기·해독·계정 목록 형식 오류를 빈 저장소로 간주하지 않습니다. 세션 파일이 실제로 없을 때만 새로 만들며, 읽을 수 없는 원본을 새 로그인으로 덮어쓰지 않습니다.
- 계정·설정은 경로별 Windows mutex 아래에서 읽기·수정·원자적 교체를 수행합니다. 잠금 획득 시간과 핸들 수명을 제한하고 비정상 종료한 소유자를 처리합니다. 설정 읽기·쓰기 실패 시 원본을 보존하며 성공하기 전에는 변경한 설정으로 저장을 시작하지 않습니다.
- 브라우저 확장 연결은 일회성 비밀과 사용자 코드 대조, 확장 자체 승인 화면, 앱의 최종 승인을 사용합니다. loopback Host·Origin·경로·본문 크기·만료·순서를 검사하고 AES-GCM과 독립 HMAC으로 세션과 진행 단계를 보호합니다. 앱은 기존 브라우저 프로필 파일을 직접 읽지 않습니다.
- 연결 서버의 요청 읽기는 헤더·본문 전체에 최대 0.75초 기한을 적용하고 연결 만료도 넘지 않습니다. 바이트를 조금씩 보내 소켓의 유휴 시간 제한을 계속 연장할 수 없습니다.
- 로컬 토큰 보관·브라우저 확인·실제 비공개 Likes 목록 접근 확인을 구분합니다. 명확한 인증 거부만 재연결로 안내하며 통신 실패·요청 제한·일반 403 때문에 연결 정보를 삭제하지 않습니다.
- API·미디어 요청의 간격과 리다이렉트에 요청 보호를 적용하고 HTTP·GraphQL 제한, 계정 잠금 및 서버가 지정한 재개 시각을 보존합니다. TLS 검증을 끄지 않습니다.

## 파일·미디어·작업 프로세스

- 공유 기록 사본의 `allowed_media_roots`는 이 PC의 파일 관리 권한으로 가져오지 않습니다. 외부 사본의 트리거·비정상 스키마를 거부하고 정상적인 로컬 폴더 이전으로 승인한 이력은 보존합니다. 이전 버전에서 이미 가져온 잘못된 로컬 승인값을 자동 판별해 제거한다고 보장하지 않습니다.
- 미리보기는 실제 디코더 형식을 제한하며 EPS 등 외부 렌더러를 부를 수 있는 형식을 확장자만으로 허용하지 않습니다. 링크·클라우드 전용 파일·디코딩 중 파일 교체를 거부하고 픽셀·출력 크기·처리 시간을 제한합니다. 사진 원본과 기존 메타데이터를 보존합니다.
- 래스터 미리보기와 원본 크기 조회는 압축된 입력도 64MiB로 제한합니다. 열린 파일의 크기와 디코더가 읽는 범위를 함께 검사해, 확인 뒤 커진 WebP 파일도 무제한으로 읽지 않습니다. 상한을 넘는 파일은 미리보기에서 제외하며 원본은 유지합니다.
- 저장 상세의 짧은 재시도는 Windows 공유·범위 잠금(32/33)으로 확인한 경우에 한정합니다. 최초 파일 서명을 고정하며 잠금 해제 사이 파일이 교체되면 표시하지 않습니다. Python이 일반 권한 오류만 반환하면 읽기 전용으로 최대 한 바이트를 확인해 잠금을 구분합니다. 영구 권한·손상·시간초과·클라우드 전용 오류를 무조건 반복하지 않습니다.
- 저장 상세의 임시 업로드 하드링크 예외는 실제 볼륨의 링크 이름을 열거하고 같은 상위 폴더에 속한 `.tmp.driveupload` 형태만 인정합니다. 다른 위치의 같은 폴더명과 일반 하드링크는 거부합니다. 이는 동기화 서비스의 신원을 인증하는 기능은 아닙니다.
- 외부 메타데이터 도구의 stdout·stderr와 줄 수를 제한합니다. Windows Job으로 도구와 자식 프로세스의 메모리를 제한하며, 상한을 넘으면 무제한 방식으로 재시도하지 않습니다. 실패 시 원본을 교체하지 않습니다.
- 메타데이터 초기 읽기·복사도 확인된 공유 잠금만 단계당 최대 1초 기다립니다. 파일 서명과 기존 20초 전체 상한을 유지하며, 추가 재시도 중 중단을 요청하면 저장된 원본·기록을 정리하는 기존 순서를 따릅니다.
- FFmpeg 변환도 별도 Windows Job으로 소유하여 저장 worker가 강제 종료되어도 변환 도구가 남지 않게 합니다. 변환에는 메타데이터 도구의 메모리 상한을 적용하지 않습니다. 프로세스 보호 초기화가 실패하면 변환 도구를 종료하고 원본 MP4를 보존합니다.
- worker IPC는 읽기·줄 길이 상한을 적용합니다. 진행 알림은 최신 상태로 합치되 저장·확인·오류·완료 이벤트의 순서를 보존합니다. 오래된 작업 결과와 닫힌 화면의 미디어 결과는 발행하지 않습니다.

## 빌드와 재배포

고정 의존성과 Git LFS 입력은 버전·크기·SHA-256을 확인합니다. Python·QML·배포 소스·번들 도구 입력과 의존성 버전을 PyInstaller 실행 전에 기록하고 빌드 후 다시 대조합니다. 이 기록에 EXE와 실행 폴더 전체 파일의 상대 경로·SHA-256을 결합하며 패키징 때도 대조하므로 소스만 수정한 뒤 이전 EXE와 묶거나 봉인 뒤 번들 QML·DLL을 바꿀 수 없습니다. ZIP 압축 뒤에도 교체 직전에 다시 대조하고, 그동안 입력이 바뀌었다면 기존 ZIP과 체크섬을 보존합니다.

실제 EXE의 Qt 시작과 오프라인 저장 초기화 보고서는 현재 버전·EXE 해시와 일치해야 합니다. 실행 폴더는 PyInstaller COLLECT 목록과 비교해 추가·누락 파일을 거부합니다. 프로젝트 소스는 명시적 허용 목록과 제한된 Python/QML 패턴만 포함하며 파일·상위 폴더의 심볼릭 링크·junction·hardlink를 거부합니다. 사용자 데이터·쿠키·프로필·개발 로그를 재귀적으로 수집하지 않습니다. Qt·FFmpeg·ExifTool의 원본 소스와 라이선스는 유지합니다.

Qt 실행 검사와 직접 ZIP 패키징은 같은 보고서 검증을 사용합니다. 창 표시·갤러리·미리보기·대화상자·종료·격리 데이터 정리 중 하나라도 빠지거나 실패하면 패키징을 거부하며, QML 오류 목록도 명시적으로 비어 있어야 합니다.

## 검증과 한계

관련 회귀는 `test_browser_bridge`, `test_file_mutex`, `test_image_security`, `test_package_release`, `test_build_snapshot` 및 파일 권한·미디어·설정 테스트를 포함합니다. 실제 Windows DPAPI를 쓰는 검사는 임시 경로와 합성 인증 정보를 사용합니다. 전체 명령과 실행 결과는 [개발 안내](development.md)와 [검증 기록](verification.md)에 있습니다.

고정 의존성의 알려진 공지 조회는 조회 시점과 버전에 한정됩니다. FFmpeg·ExifTool·Qt·Python의 모든 네이티브 코드에 대한 퍼징이나 취약점 부재를 보증하지 않습니다. 같은 사용자 권한으로 앱·브라우저·메모리를 수정할 수 있는 악성코드까지 격리하는 설계는 아닙니다. 실제 X 로그인·추가 인증·장기 실행과 확장 스토어 심사는 오프라인 테스트와 구분합니다. Windows 코드 서명은 제공하지 않습니다.

이전 구현의 TCP/DevTools 로그인 및 Tk 아이콘 검토는 현재 지원 경로가 아닙니다. 날짜별 원문은 [1.1.3 소스 기록](https://github.com/chobby-f/LuvBox/tree/v1.1.3/docs)과 [1.2.0 소스 기록](https://github.com/chobby-f/LuvBox/tree/v1.2.0/docs)에서 확인할 수 있습니다.
