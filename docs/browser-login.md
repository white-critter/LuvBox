# X 로그인 연결

LuvBox는 평소 쓰는 웹 브라우저의 X 로그인을 연결해 사용합니다. 기본 방법은 **브라우저 연결(확장)**이며, 확장을 쓰기 어려운 환경에서는 **고급 연결 · 토큰 입력**을 쓸 수 있습니다.

## 브라우저로 연결하기

1. 앱의 **X 연결** 창에서 사용할 브라우저(Chrome·Edge·Firefox)를 고릅니다. 선택한 브라우저의 일반 프로필에 연결 확장을 설치하고 X에 로그인해 두세요.
2. **X 계정 연결**(또는 **다시 연결**)을 누릅니다. 앱과 브라우저 확장에 같은 8자리 연결 코드가 보이는지 확인하고 체크하면 X 계정을 자동으로 확인합니다.
3. 브라우저 확장에서 **@아이디 연결**을 누른 뒤, 앱으로 돌아와 **이 계정 연결 승인**을 누르면 연결이 끝납니다.
4. 처음 연결할 때나 연결을 시작한 뒤 잠시 응답이 없으면 **확장 설치·연결 도움말**이 펼쳐집니다. 화면의 순서나 [브라우저 연결 확장 안내](../assets/browser-extension/README.md)를 따라 확장을 설치하고 켜 두세요.

## 연결 확장 설치와 유의 사항

- Chrome·Edge는 확장 관리 화면에서 개발자 모드를 켜고 안내된 폴더를 불러오며, Firefox는 디버깅 화면의 임시 부가 기능 로드에서 안내된 폴더의 `manifest.json` 파일을 고릅니다.
- Firefox의 임시 부가 기능은 브라우저를 다시 시작하면 꺼지므로, 다시 연결할 때 한 번 더 불러와야 합니다.
- 시크릿(사생활 보호) 창이나 확장 설치가 막힌 환경에서는 브라우저 연결이 동작하지 않습니다.
- 앱을 업데이트한 뒤 연결이 잘 되지 않으면 브라우저의 확장 관리 화면에서 확장을 **새로고침**한 뒤 다시 연결하세요. 이미 연결해 둔 계정은 앱을 업데이트해도 그대로 유지됩니다.

## 계정 확인과 개인정보 보호

- 계정을 확인할 때는 브라우저에서 X 홈 화면을 잠시 열어 현재 로그인된 본인의 아이디와 이름만 확인하고, 자동으로 연 탭만 닫습니다.
- 브라우저에 저장된 비밀번호나 다른 사이트 정보는 읽지 않습니다.
- 연결을 승인한 뒤에도 앱에서 최종 승인을 눌러야 저장이 완료됩니다. 여러 계정을 연결해 두었다면 저장 화면에서 사용할 계정을 골라 쓸 수 있습니다.
- 연결 정보는 이 PC의 현재 Windows 계정에만 암호화해 보관합니다.

## 고급 연결 (토큰 입력)

1. 연결 창 아래의 **고급 연결 · 토큰 입력**을 펼칩니다.
2. 브라우저에서 X에 로그인한 뒤 개발자 도구(F12) › 애플리케이션(Application) › 쿠키(Cookies) › `https://x.com`에서 `auth_token` 값을 복사해 입력하고 **토큰 저장**을 누릅니다.
3. 저장 화면에서 사용할 본인의 X 아이디를 확인합니다.

로그인 토큰은 비밀번호와 같으니 다른 사람에게 절대 보내지 마세요.

## 연결 상태 안내

- **계정 확인됨 / 연결됨**: 계정이 정상적으로 연결되어 저장을 시작할 수 있습니다.
- **토큰 저장됨**: 토큰이 저장되었으며, 실제 저장을 시작할 때 X 접근 가능 여부를 확인합니다.
- **X 로그인이 만료됐습니다**: 브라우저에서 로그아웃했거나 로그인 유효 기간이 끝난 상태입니다. **X 연결**에서 다시 연결하면 되며, 이미 저장한 사진과 정리 기록은 지워지지 않습니다.
- 일시적인 인터넷 연결 오류나 X 서버 지연 때문에 기존 연결 정보가 저절로 지워지지는 않습니다.
