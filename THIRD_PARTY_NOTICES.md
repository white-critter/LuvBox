The application folder configuration bundles Python, Qt/PySide6, Pillow, gallery-dl, the minimal local FFmpeg executable and the complete local ExifTool runtime under _internal. The executable and _internal directory must be distributed and kept together; no per-launch runtime extraction is needed. Account authentication, downloaded media, settings and local records are not included in the release. Authentication uses the app's browser connection or direct token input; the downloader also accepts Netscape cookies.txt for command-line jobs. No browser runtime or separate FFmpeg installation is required. The optional imageio-ffmpeg development fallback and its Gyan binary are excluded from the executable. Builds require isolated frozen Qt and download startup checks before packaging; these do not validate actual X authentication/downloads or native schedule changes. Windows system ICU is not redistributed; incompatible ICU files from unrelated build-environment tools are rejected.

## Qt 6.10.3 development distribution

Qt Quick, Qt Quick Controls (Fusion and Basic fallback), Qt Quick Dialogs, Qt QML and Qt Multimedia are used by the new UI. The build uses Qt/PySide dependency hooks with project plugin/import filters, not a whole-PySide collection. Unused PDF, Virtual Keyboard, QML debugger/Quick3DUtils and optional Mesa software OpenGL dependencies are excluded at collection time and rejected by packaging if they reappear. The Windows default Direct3D renderer is unchanged. The Qt Quick Dialogs QML plugins and their QtQuickDialogs2 libraries are collected as QML/native dependencies; there is no separate PySide6.QtQuickDialogs2 Python module.

Portable Strawberry Perl notices are included in exiftool_files/Licenses_Strawberry_Perl.zip. setup.ps1 verifies the pinned package SHA256 and version. The app never downloads tools at runtime.

Videos use the highest bitrate of directly provided MP4 variants. New X animated GIF media is downloaded as MP4 and converted locally to GIF. Existing MP4 files are preserved. ExifTool writes XMP/QuickTime source URLs locally without re-encoding media or requesting X; GIF conversion is a separate local step. Local records use standard-library SQLite.
