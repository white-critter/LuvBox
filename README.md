# 러브박스 (LuvBox) 1.12.6

**X에서 좋아요한 사진·영상·GIF를 내 PC에 저장하세요.** 모아 둔 미디어를 갤러리에서 다시 찾고, PC에 있는 사진 폴더도 정리할 수 있습니다.

**[최신 LuvBox.exe 받기](https://github.com/white-critter/LuvBox/releases/latest/download/LuvBox.exe)** · Windows 10·11 (64비트) · 설치 없이 실행

![LuvBox 갤러리에서 사진을 검색하고 즐겨찾기와 태그로 걸러 보는 화면](docs/images/gallery.png)

## 할 수 있는 일

- **좋아요 자동 저장** — 저장할 폴더와 실행 시각을 지정하면 새로 좋아요한 미디어를 매일 확인해 저장합니다.
- **검색과 AI 태그** — 갤러리에서 즐겨찾기·작성자·날짜로 사진을 찾습니다. **AI 태그 관리**에서 원하는 태그를 추가하고 사진을 PC 안에서 자동 분류할 수 있습니다.
- **중복 사진 정리** — PC의 사진 폴더에서 동일한 사본과 크기·화질이 다른 버전을 비교하고, 고른 파일을 Windows 휴지통으로 보낼 수 있습니다.

화면은 예시 계정과 AI로 만든 사진을 사용해 촬영했습니다.

## 시작하기

1. 다운로드한 `LuvBox.exe` 하나를 실행합니다.
2. **X 연결**에서 X에 로그인한 Chrome·Edge·Firefox를 고르고 앱의 확장 설치·계정 승인 안내를 따릅니다.
3. **저장 위치**에서 폴더를 고르고 **저장 시작**을 누릅니다.

PC에 있는 사진은 **폴더 정리** 탭에서 바로 열 수 있습니다.

X 로그인 정보는 이 PC에 암호화해 보관합니다. 새 버전은 앱 상단의 **업데이트** 알림에서 받을 수 있습니다.
