# XlikeSaver 1.1.0

내 X(트위터) 계정에서 Like한 게시물의 사진·동영상·움직이는 GIF를 저장하는 Windows 프로그램입니다.

## 실행하기

`release/XlikeSaver-1.1.0.exe`를 더블클릭하세요. 실행 파일 이름에 버전이 붙어 있어 이전 버전을 실행 중이어도 새 버전을 만들거나 받을 수 있습니다. Python이나 IDE 설치 없이 실행 파일 하나로 사용할 수 있습니다. 처음 실행할 때 내부 도구를 임시 폴더에 풀어 잠시 시간이 걸릴 수 있습니다.

배포용 `release/XlikeSaver-1.1.0.zip`에는 exe, 짧은 사용 안내, 소스와 라이선스가 들어 있습니다. 압축을 풀고 exe를 실행하세요.

## 사용하기

1. 본인의 X 아이디와 저장 경로를 입력합니다.
2. **로그인 연결**에서 인증 토큰을 한 번 저장하거나 Netscape 형식의 `cookies.txt`를 선택합니다. **사용 방법**에서 방법을 확인할 수 있습니다.
3. 필요하면 **저장 옵션**을 바꾸고 **저장 시작**을 누릅니다.
4. 저장한 파일·게시일 범위·실행 내역은 **기록 · 통계**에서 확인합니다. 파일을 선택하고 **트윗 열기**를 누르면 출처를 볼 수 있습니다.

토큰과 쿠키는 로그인 인증정보입니다. 다른 사람에게 보내지 마세요. 인증 토큰은 현재 Windows 사용자만 읽을 수 있도록 암호화해 보관하며, 쿠키 파일은 직접 안전하게 보관해야 합니다.

## 저장 옵션

기본값은 **구분 없이 저장**, **계정별 폴더 끔**, **새 Like만 빠르게 확인**입니다. 파일을 선택한 저장 경로에 바로 넣습니다.

| 설정 | 예시 |
| --- | --- |
| 구분 없이 저장 | `D:/X사진/게시물ID_1.jpg` |
| 작성자별 폴더 | `D:/X사진/작성자/게시물ID_1.jpg` |
| 저장일별 폴더 | `D:/X사진/2026-10-04/게시물ID_1.jpg` |
| 계정별 폴더 켬 | 위 경로 앞에 `내아이디/` 추가 |

저장일은 파일 저장이 끝난 날의 한국 날짜입니다. 계정별 폴더 옵션을 바꿔도 기존 파일은 제자리에 두고 건너뛰며, 새 파일부터 바뀐 위치에 저장합니다. 작성자별·저장일별·구분 없이 정리 방식을 바꾸면 방식별 기록을 사용하므로 별도 복사본이 생길 수 있습니다.

사진은 항상 저장 대상이며 한 게시물의 여러 사진도 모두 저장합니다. 동영상은 제공된 직접 MP4 중 최고 비트레이트로 저장합니다. X의 움직이는 GIF도 실제 제공 형식인 MP4로 저장합니다. 동영상·GIF는 개별 파일 용량을 제한할 수 있으며 기본 200MiB, 0은 제한 없음입니다. 직접 MP4가 없는 HLS 영상은 지원하지 않습니다.

파일 안에도 원본 트윗 주소를 기록합니다. 기존 파일은 **기록 · 통계 → 기존 파일에 출처 기록**으로 처리할 수 있습니다. 출처 기록은 미디어를 다시 받거나 재인코딩하지 않으며, 작업 동안 ExifTool 하나를 띄워 두고 재사용합니다.

## 확인 범위: 새 Like만 빠르게 / 전체

X의 Like 목록은 최근에 누른 Like부터 나옵니다. **새 Like만 빠르게 확인**은 이미 저장한 파일이 100개 연속으로 나오면 이전 확인 지점에 도달한 것으로 보고 멈춥니다. Like가 수천 개여도 새 항목만 확인하므로 목록 요청이 크게 줄어듭니다.

이 방식은 직전 실행이 목록 끝까지 정상 종료됐을 때만 안전합니다. 그래서 다음 경우에는 자동으로 **전체 목록**을 확인하고, 그다음 실행부터 다시 빠르게 확인합니다.

- 첫 실행, 또는 이 정리 방식(작성자별·저장일별·구분 없이)의 첫 실행
- 직전 실행이 중단·오류·시험 저장(20개)으로 끝났거나 비정상 종료된 경우
- 동영상·GIF 포함 여부나 영상 용량 제한을 바꾼 경우

예전 Like를 다시 훑고 싶으면 **전체 목록 다시 확인**을 고르세요.

## 정기적으로 자동 저장하기

인증 토큰 연결로 한 번 저장을 마친 뒤, **사용 방법 → 예약 명령 복사**를 누르고 명령 프롬프트(cmd)에 붙여 넣어 실행하면 Windows 작업 스케줄러가 매일 오전 9시에 새 Like만 저장합니다. 등록되는 명령은 다음과 같은 형태입니다.

```bat
schtasks /Create /TN "XlikeSaver 자동 저장" /SC DAILY /ST 09:00 /TR "\"C:\경로\XlikeSaver-1.1.0.exe\" --run-saved" /F
```

- 예약 실행은 마지막으로 저장을 시작할 때의 설정(아이디·저장 경로·정리 방식·미디어 옵션)을 사용하며 창 없이 실행됩니다.
- 결과는 `%LOCALAPPDATA%/XlikeSaver/logs/`에 남고 최근 30개만 보관합니다. **사용 방법 → 예약 실행 기록**으로 열 수 있습니다.
- cookies.txt 연결은 파일 경로를 저장하지 않으므로 예약 실행을 지원하지 않습니다.
- 앱에서 저장 작업을 실행 중이면 예약 실행은 겹쳐 실행하지 않고 종료합니다.
- 실행 파일을 옮기거나 새 버전으로 바꾸면 다시 등록하세요. 해제: `schtasks /Delete /TN "XlikeSaver 자동 저장" /F`
- 너무 자주 예약하지 마세요. 요청 간격을 지켜도 계정 제한 위험은 남습니다.

## 기록과 다시 시작

기록 DB는 `저장 경로/.xlikesaver/계정명/`에 모아 보관합니다. 사진과 영상은 이 폴더 밖에 저장됩니다. **기록 위치**에서 확인할 수 있습니다. 인증 연결과 설정은 `%LOCALAPPDATA%/XlikeSaver/`에 별도로 보관합니다.

기존 `저장 경로/계정명/`의 기록은 처음 사용할 때 복사해 이어서 사용합니다. 이전 사진과 DB는 그대로 보존하며, 예전에 받은 파일도 계속 건너뜁니다. 기록을 유지하려면 저장 경로와 `.xlikesaver` 폴더를 함께 보관하세요. 앱에서 저장 경로를 바꾸면 해당 계정의 기록을 새 `.xlikesaver/계정명/` 폴더로 자동 복사해 이어서 사용합니다. 새 위치에 기록이 있어도 합쳐서 유지합니다. 기존 사진·영상과 원본 DB는 그대로 두며, 새 파일만 새 위치에 저장합니다. 직접 입력한 경로는 입력을 마치거나 저장·기록 보기를 누를 때 적용됩니다. 이전에 실패하면 원래 저장 경로를 유지합니다.

중단·오류 이후에도 완료 기록은 유지합니다. 다음 실행은 목록 앞에서 다시 확인하며 정확한 페이지 위치에서 이어지는 방식은 아닙니다. 삭제되거나 접근할 수 없는 게시물과 X가 제공하지 않는 오래된 목록은 받을 수 없습니다.

Like한 시각을 복원하지 못하므로 날짜 범위 선택은 없습니다. 통계의 가장 오래된 게시일은 저장 기록 중 최솟값이며, 그 날짜까지 모든 Like를 빠짐없이 저장했다는 뜻은 아닙니다. **자세히 보기**의 퍼센트는 현재 파일의 진행률입니다. 저장 작업 중에 **기록 · 통계**를 열면 저장 폴더 전체 재확인은 건너뛰고 현재 기록만 보여 줍니다. 작업이 끝난 뒤 **새로고침**을 누르면 폴더를 다시 확인합니다.

## 제한이나 오류가 나면

요청 제한·인증 오류·서버 오류가 나면 자동 재시도하지 않고 멈춥니다. 완료한 파일은 보존합니다. 화면의 안내를 확인한 뒤 수동으로 다시 시작하세요. `429`는 안내한 시각까지 기다리고, 계정 잠금은 X에서 직접 확인합니다. 디스크 부족이나 쓰기 권한 오류는 해당 문제를 해결한 뒤 재시작합니다. 국가 제한·연령 제한·볼 수 없는 미디어처럼 게시물마다 생기는 상황은 안내만 남기고 건너뜁니다.

이 앱은 X 웹사이트의 비공식 API를 사용합니다. 요청 간격과 제한 시 중단 기능은 계정 제한을 예방한다고 보장하지 않습니다. 자세한 처리 방식은 [개발·문제 해결 안내](docs/development.md)를 참고하세요.

## 코드 수정·빌드

VS Code에서 이 폴더 또는 `XlikeSaver.code-workspace`를 열고 `.venv/Scripts/python.exe`를 선택합니다. **XlikeSaver 앱** 실행 구성으로 F5를 누르거나 `run.bat`를 실행하세요.

```powershell
.\setup.ps1
.\run.bat
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\build.ps1
```

빌드는 `release/XlikeSaver-<버전>.exe`와 소스·라이선스를 포함한 `release/XlikeSaver-<버전>.zip`, 체크섬 `release/SHA256-<버전>.txt`를 만듭니다. 버전은 `xlikesaver/__init__.py`에서 읽습니다. 같은 버전의 exe가 실행 중이면 덮어쓰지 않고 안내 후 멈춥니다. `build/`는 중간 작업 폴더이며 배포하지 않습니다. 사용자 토큰·쿠키·사진·DB는 배포본에 포함하지 않습니다. 재배포할 때는 ZIP의 소스와 라이선스도 함께 제공하세요.
