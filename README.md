# 러브박스 (LuvBox) 1.10.0

**좋아요한 사진을 쉽게 저장하고 보는 Windows 앱.**

Qt Quick 화면과 기존 저장 엔진을 사용하는 Windows 앱입니다. 버전은 `1.1.0`, `1.1.1`처럼 숫자로만 관리합니다.

## 사용 흐름

1. **X 연결** — 사용할 Chrome·Edge·Firefox를 선택하고 브라우저의 계정을 확인해 연결합니다.
2. **저장 위치 → 저장 시작** — 사진·동영상·GIF를 저장합니다.
3. **갤러리** — 검색·필터·정렬하고 파일을 열거나 선택해 휴지통으로 이동합니다.
4. **설정 › 고급** — 자동 저장 예약, 실행 기록을 확인합니다. 저장하지 못한 미디어는 갤러리의 **저장 못 한 미디어** 버튼으로도 엽니다.

앱은 항상 **저장** 화면에서 시작합니다. 갤러리는 페이지 버튼 없이 이어서 스크롤하며, 목록의 썸네일은 작게·보통·크게 중에서 고르고, 고른 크기는 다음 실행에도 유지됩니다. 긴 갤러리의 오른쪽 스크롤바는 계속 표시됩니다.

갤러리 위쪽은 두 줄입니다. 첫 줄에 검색과 **정렬·종류·크기**, 둘째 줄에 빠른 필터(**즐겨찾기, 중복 사진, AI 분류, 작성자, 해시태그, 내 태그, 날짜**)와 오른쪽의 **미리보기·새로고침·여러 개 선택**이 있습니다. 필터는 고르는 즉시 적용되고 켜진 필터는 붉게 표시되며, 걸린 필터가 있을 때만 **× 필터 지우기**가 나옵니다. **날짜**를 누르면 기준(게시일·저장일)과 시작·종료 날짜가 옆에 펼쳐집니다. 그 아래 한 줄에 사진 수와 적용된 필터, 가장 최근 안내와 진행 상황이 표시됩니다. **여러 개 선택** 중에 쓰는 동작(불러온 항목 선택, 선택 해제, 분류 가르치기, 태그 추가, 휴지통으로)은 창 아래의 막대에 모여 있고, 같은 버튼(**선택 끝내기**)이나 Esc로 끝냅니다. **통계**와 **단축키**는 제목 줄에서 한 번에 엽니다. 저장 중에 새 사진이 생기면 **새로고침**이 **새 사진 보기**로 바뀝니다.

앱 창은 1280×860으로 열리고 마지막 크기·위치·최대화 상태를 기억합니다. 갤러리의 타일은 **Shift+클릭**으로 범위를, 빈 곳이나 타일 위에서 **끌어서** 사각형에 닿은 사진을 선택합니다(Ctrl을 누르면 기존 선택에 추가). 휠은 한 칸에 타일 반 줄 남짓 움직이고 계속 굴리면 4배까지 빨라지며, 설정·기록·통계 같은 다른 목록도 같은 방식으로 스크롤합니다. 상단의 **AI 분류**를 누르면 분류별 사진 수가 보이고 그 분류만 보거나 자동분류를 실행할 수 있습니다. **통계**는 파일 수·용량·작성자·월별 현황을 보여 주며 기본 크기에서는 스크롤 없이 한 화면에 들어옵니다.

갤러리에서 **Ctrl+F**를 누르면 검색어가 선택되어 바로 바꿀 수 있고, **Ctrl+A**로 불러온 사진 전체 선택, **Esc**로 선택 해제, **D**로 중복 사진 필터, **B**로 즐겨찾기 필터를 빠르게 켜고 끌 수 있으며, **S**로 라이브러리 통계 요약 대화상자를 바로 열 수 있습니다. 제목 줄의 **단축키** 버튼이나 **F1**로 갤러리·미리보기 단축키 목록을 봅니다. 작성자·정렬 같은 목록에 포커스가 있을 때는 글자 키를 목록이 받습니다. Tab으로 이동하는 버튼과 스위치는 테두리로 현재 위치를 표시합니다. 목록을 읽지 못한 경우에는 오류 원인을 표시하며, 빈 갤러리로 안내하지 않습니다.

**중복 사진**을 누르면 그리드 대신 묶음 보기가 열립니다. **중복 검사**는 기본으로 내용이 완전히 같은 파일만 찾고, **화질만 다른 사진 포함**을 켜면 크기·화질만 다르게 다시 저장된 같은 사진도 찾습니다. 이때는 지각 해시가 가까운 사진끼리 화면을 직접 비교해 평균 99% 이상 같고 부분적으로도 다르지 않을 때만 묶습니다. 묶음마다 남길 한 장(즐겨찾기, 그다음 큰 파일)에 **남김**, 나머지에 **사본**을 표시하며, 묶음의 **사본 선택**이나 **사본 일괄 선택**으로 골라 휴지통으로 보냅니다. 같은 사진이 아니거나 모두 남기려는 묶음은 **중복 아님**을 누르면 목록에서 빠지고 다음 검사에서도 다시 묶이지 않습니다(사진은 그대로이며, 같은 새 사진이 저장되면 함께 다시 보입니다). 묶음 안의 몇 장만 다른 사진이면 그 사진을 눌러 고른 뒤 **선택한 N장만 중복 아님**을 누릅니다. 고른 사진만 빠지고 나머지는 묶음으로 남습니다. 표시하거나 정리한 뒤에도 목록은 보던 자리에 머뭅니다. 위쪽의 **중복 아님 되돌리기**는 방금 누른 것을, **중복 아님 N개 초기화**는 표시한 것 전부를 다시 검사 없이 묶음으로 돌려놓습니다. 1.6.x가 만든 묶음(비슷해 보이기만 한 사진 포함)은 저장된 파일 해시로 다시 계산해 정리합니다. 검사는 파일 확인과 사진 비교 단계를 구분하고 **검사 중단**으로 멈출 수 있습니다. 현재 파일 확인이 끝나면 중단되며, 이미 저장한 유효한 해시는 다음 검사에서 재사용합니다. 파일 크기가 같아도 수정 시각이나 파일 식별자가 바뀌면 다시 검사합니다. 한 파일이 폴더 구성 방식마다 따로 기록되어 있어도 사진 한 장으로 다루며, 중복 보기에서 보내는 파일은 옮기기 직전에 같은 내용의 다른 파일이 지금 남아 있는지 다시 확인하고, 확인되지 않으면 그대로 둡니다(묶음을 통째로 골라도 한 장은 남습니다). 폴더를 병합한 뒤에는 중복 검사를 다시 실행해 사본 목록을 갱신하세요. 사본 일괄 선택은 현재 불러온 사진만 대상으로 하며 기존 선택과 합쳐 최대 2,000개입니다.

사진을 여는 미리보기와 저장 전 확인창은 앱 창을 넓게 사용합니다. 위쪽의 **창 최대화**를 누르면 앱 전체가 최대화되고 미리보기도 함께 커지며, **창 복원**으로 돌아옵니다. 갤러리 미리보기의 게시물 본문은 **본문 보기 / 본문 접기**로 펼치고 접습니다. 사진은 비율을 유지해 표시합니다.

미리보기에서 휠이나 **＋ / −**로 확대·축소하고, 확대된 사진을 드래그해 이동합니다. **화면 맞춤**으로 돌아오거나 지원하는 사진에서 **원본 100%**를 볼 수 있습니다. 갤러리는 **이전 / 다음**과 좌우 방향키로 탐색하며, **Delete** 키로 현재 사진을 휴지통으로 보낼 수 있습니다(확인 후 이동). 사진을 휴지통으로 옮겨도 갤러리는 보던 위치에 그대로 있고 옮긴 타일만 빠지며, 미리보기에서 옮겼다면 다음 사진의 미리보기로 돌아옵니다. AI 자동분류·중복 검사·분류 가르치기가 끝날 때도 그 결과로 목록이 달라지는 필터를 쓰고 있지 않으면 보던 위치와 열어 둔 미리보기를 유지합니다. 원본 배율은 1,600만 화소 이하의 확인된 사진에서 지원하며 GIF·영상은 확대·축소와 화면 맞춤을 사용합니다.

소리가 있는 영상은 미리보기에서 기본 음소거로 재생하며 **소리 켜기 / 소리 끄기**로 조절합니다. 다른 파일을 열거나 닫으면 다시 음소거됩니다.

저장 화면의 **자세히 보기**를 켜면 최근 저장한 파일과 작성자·게시물 본문·게시 시각이 표시됩니다. GIF·영상은 첫 장면을 정지 사진으로 보여 줍니다. 숨겨 두면 미리보기를 만들지 않습니다.

설정에서는 저장 방식과 미디어 옵션을 바꿉니다. 갤러리의 빠른 필터는 작성자·해시태그·내 태그 목록, **로컬 AI(CLIP) 자동분류**(`#일러스트`, `#인물`, `#동물`, `#짤·텍스트`, `#풍경·배경`)와 달력 선택기를 제공하며, **통계 대화상자**, **★ 즐겨찾기**(단축키 **F**), **유사·중복 이미지 탐지·사본 일괄 선택**을 지원합니다. 저장이 끝나면 새로 받은 사진은 알아서 분류합니다(앱에서 한 저장은 끝난 직후, 예약 자동 저장은 그 실행이 끝날 때, 남은 것은 앱을 열 때). AI 모델이 이 PC에 이미 있을 때만 동작하고 이 기능이 모델을 내려받지는 않으며, 설정의 **저장한 사진 자동 AI 분류**로 끌 수 있습니다. AI 자동분류는 **분류 중단**으로 멈출 수 있으며, 이미 처리된 사진의 라벨과 특징값은 유지됩니다. AI 태그 초기화는 확인 후에만 실행되고, 분류가 중간에 실패하면 그 사진은 다음 실행에서 다시 분류합니다. 열 수 없는 파일은 크기나 수정 시각이 바뀌기 전까지 다시 열지 않습니다. 진행 건수는 한 묶음이 끝날 때마다 갱신됩니다. 사본 선택은 마지막 중복 검사에서 저장한 묶음을 사용합니다. 원본 파일이 삭제되거나 이동된 항목은 갤러리·미리보기·저장 상세에서 안내 박스로 표시됩니다.

테마는 앱 아이콘에 맞춘 **블랙·레드 하나**입니다. 검은 배경에 빨간 강조색을 사용하며 밝기·테마 선택 메뉴는 없습니다. 시작 화면과 같은 은은한 붉은 빛이 창 위쪽과 대화상자에 들어가고, 저장하는 동안에는 저장 화면의 빛이 천천히 밝아졌다 어두워집니다. 빨간 강조 버튼은 화면·대화상자마다 하나이며, 설정은 넓은 창에서 두 단으로 나뉘어 **고급**을 펼쳐도 스크롤 없이 보입니다.

## 연결과 개인정보

- 기본 연결은 브라우저 확장을 사용합니다. 선택한 Chrome·Edge·Firefox로 설치 안내·X 열기·계정 연결을 진행하고 선택을 기억합니다. 브라우저가 실제로 연 일반 프로필에 확장을 설치하고 X에 로그인해 두세요. 별도 프로필을 추정하거나 강제로 바꾸지 않습니다.
- **X 계정 연결**을 누르면 확장 응답·계정 확인·최종 승인 단계를 표시합니다. 설치 도움말은 접어 두며, 약 8초간 응답이 없으면 펼칩니다. 응답 없음은 미설치 확정이 아니므로 브라우저·프로필·확장 활성 상태를 함께 확인하세요.
- 앱과 확장의 코드가 같음을 체크하면 계정을 자동 확인합니다. 브라우저에서 **@아이디 연결**, 앱에서 **이 계정 연결 승인**을 눌러 완료합니다. [확장 설치 안내](assets/browser-extension/README.md)를 참고하세요. 확장의 스토어 배포·자동 설치는 아직 제공하지 않습니다.
- 연결창에 확장 폴더 경로가 표시됩니다. Chrome의 폴더 창은 보통 ‘문서’에서 열리므로, 그 경로를 주소창에 붙여 넣고 `manifest.json`이 있는 폴더를 선택합니다. 확장은 자동 설치하지 않으며 ZIP을 그대로 불러올 수 없습니다.
- 확장은 `%LOCALAPPDATA%\LuvBox\browser-extension\chromium` 또는 `firefox`에 복사하므로 앱 버전을 바꾸거나 이전 버전 폴더를 지워도 유지됩니다. Firefox의 임시 확장은 브라우저를 다시 시작하면 다시 불러와야 합니다.
- [스토어 제출 준비 안내](docs/browser-extension-store.md)와 제출용 패키지 생성 도구는 제공하지만, 실제 스토어 등록·승인이 끝난 것은 아닙니다.
- 연결 정보는 Windows 사용자 계정에 암호화해 저장합니다. 토큰·쿠키는 다른 사람에게 보내지 마세요.
- **고급 연결 · 토큰 입력**은 대체 수단입니다. **토큰 보관** 후에도 연결창은 열어 두며 실제 인증 성공으로 표시하지 않습니다. 저장 화면에서 본인 X 아이디를 확인하세요.
- `연결 정보 저장됨`, `브라우저 계정 확인됨`, `X 목록 접근 확인됨`, `다시 연결 필요`를 구분합니다. 실제 사용 확인은 저장 중 좋아요 목록의 인증 응답을 근거로 하며, 통신 오류·요청 제한 때문에 저장한 연결을 지우지 않습니다.

## 설치와 업데이트

- 릴리스에서 **`LuvBox.exe` 하나**를 받아 원하는 폴더에 두고 실행합니다. 압축을 풀 필요가 없습니다.
- 새 버전을 처음 실행할 때 한 번만 앱을 `%LOCALAPPDATA%\LuvBox\app\<버전>\`에 풀어 둡니다(약 270MB). 그동안 시작 화면이 “처음 실행 준비 중 · 한 번만 걸려요”와 진행 막대를 보여 주고, 다음 실행부터는 풀지 않고 바로 엽니다. 지금 버전과 바로 이전 버전의 폴더만 남기고 더 오래된 것은 지웁니다.
- 실행기는 Windows 10·11에 기본으로 들어 있는 .NET Framework 4.x를 사용합니다. 따로 설치할 것은 없습니다.
- 코드 서명이 없어 처음 실행할 때 Windows가 경고할 수 있습니다. 릴리스의 `SHA256-<버전>.txt`와 받은 `LuvBox.exe`의 해시가 같은지 확인한 뒤 실행하세요.
- **업데이트**: 앱이 시작할 때 하루에 한 번 GitHub의 최신 릴리스를 확인하고, 새 버전이 있으면 저장·갤러리 화면 위에 변경 사항과 함께 알립니다. **업데이트**를 누를 때만 새 `LuvBox.exe`와 체크섬 파일을 받아 릴리스 서명과 SHA-256을 확인한 뒤 지금 쓰는 `LuvBox.exe`와 바꿉니다. 서명은 이 저장소 관리자의 PC에만 있는 키로 만들며, 서명이 없거나 맞지 않는 릴리스는 받지 않습니다. 실행 중인 앱은 건드리지 않으므로 하던 일을 계속할 수 있고, **지금 다시 시작**을 누르거나 다음에 열 때 새 버전으로 열립니다.
- 새 버전 확인은 **설정 › 업데이트**에서 끄거나 **지금 확인**으로 직접 할 수 있습니다. 공개된 릴리스 정보만 읽으며 이 PC나 계정에 관한 것은 보내지 않습니다.
- 설정·로그인·기록은 `%LOCALAPPDATA%\LuvBox`에 있어 그대로 이어집니다.
- 자동 저장 예약은 `LuvBox.exe`가 있는 자리를 실행합니다. 앱 안에서 업데이트하면 같은 예약이 새 버전을 실행하므로 다시 걸 필요가 없습니다. `LuvBox.exe`를 다른 폴더로 옮겼다면 **설정 › 고급 › 자동 저장 설정**에서 현재 버전으로 변경하세요.
- **1.7.x 이하에서 올 때**: 최신 `LuvBox.exe`를 한 번 직접 받아야 합니다(1.8.0부터는 앱 안에서 받습니다). 이전 버전의 폴더와 ZIP은 지워도 됩니다. 자동 저장 예약이 있었다면 위 메뉴에서 한 번 현재 버전으로 변경하세요. 그다음 버전부터는 앱 안에서 받습니다.
- 작업 표시줄에 두려면 실행 중인 LuvBox 창의 아이콘을 고정하세요. 고정한 아이콘은 `LuvBox.exe`를 실행하므로 업데이트 뒤에도 그대로 씁니다.
- 소스 코드와 라이선스 고지는 같은 릴리스의 `LuvBox-<버전>-source-licenses.zip`에 있습니다.
- 지우려면 `LuvBox.exe`와 `%LOCALAPPDATA%\LuvBox\app` 폴더를 지웁니다. 같은 `LuvBox` 폴더의 나머지에는 설정·로그인·기록이 있으므로, 그것까지 없애려는 때만 폴더 전체를 지우세요.
- 1.1.5 이하 폴더에서 불러온 브라우저 확장은 한 번 위 확장 폴더로 다시 불러와 주세요.
- 새 연결 단계 표시를 사용하려면 앱의 **X 연결**을 한 번 연 뒤 브라우저 확장 관리에서 **새로고침**해 확장을 **1.1.0**으로 갱신하세요. 기존 **1.0.0** 확장도 계정 전달은 가능하지만 단계 표시는 지원하지 않습니다. 이미 저장한 계정은 다시 연결할 필요가 없습니다.

## 저장 규칙

- 새 파일명: `작성자ID_게시물ID_번호.jpg`. 기존 이름도 계속 인식하며, 기존 파일은 자동으로 이름을 바꾸지 않습니다.
- 파일 메타데이터의 작성자·본문·원본 링크·숫자 계정 ID는 각각 분리합니다. 기존 타인 메타데이터는 보존합니다.
- 저장 전 확인을 켜면 사진·GIF·영상을 보고 저장하거나 건너뜁니다. 확인창을 닫으면 저장을 중단합니다.
- 기존 로그인·설정·기록과 다운로드 엔진을 그대로 사용합니다. 원래 파일을 새 UI 전환 때문에 이동하거나 지우지 않습니다.

## 소스에서 실행

Windows 10·11 64비트, 보안 수정이 적용된 Python 3.12 이상이 필요합니다. 현재 최소 버전은 3.12.16·3.13.18·3.14.10·3.15.2이며 준비·빌드 시 확인합니다.

```powershell
.\setup.ps1
.\run.bat
```

`run.bat`와 `entry.py`는 PySide6 + Qt Quick 화면을 실행합니다.

빌드는 `build.ps1`에 구성돼 있으며 앱을 `LuvBox.exe` 하나로 묶고, 앱·Qt/PySide·미디어 구성요소의 버전별 원본 소스와 라이선스 고지를 `LuvBox-<버전>-source-licenses.zip`으로 함께 만듭니다. 묶은 실제 `LuvBox.exe`를 실행기부터 시작해 풀기·창 표시·갤러리·사진 미리보기·설정·연결창·종료와 다운로드 초기화를 격리 확인한 뒤에만 배포 파일을 만듭니다. 이 점검은 사용자 로그인·미디어·예약을 사용하지 않으며 실제 X 인증·다운로드·예약 변경 확인을 대신하지 않습니다. [소스·재배포 자료](tools/qt/README.md)를 같은 버전의 실행 파일과 함께 공개하세요. 변경 내용은 [CHANGELOG](CHANGELOG.md), 구조와 검사·빌드 절차는 [개발 안내](docs/development.md)에 있습니다.

## 자동 저장·기록·저장 못 한 미디어

- **설정 › 고급 › 자동 저장 설정**에서 매일 실행할 시각을 등록·변경·해제합니다(저장 화면의 **자동 저장 설정**으로도 열 수 있습니다). 예약은 하나이며 실행 시 저장된 계정·폴더·옵션을 사용합니다. 예약이 없거나 조회에 실패해도 상태를 확인할 수 있습니다.
- **갤러리 → 여러 개 선택**에서 현재 불러온 파일을 선택해 Windows 휴지통으로 이동합니다. 저장 중에도 파일을 고를 수 있으며(버튼·Ctrl+클릭·Space), 휴지통 이동은 작업이 끝난 뒤 사용할 수 있습니다. 선택 뒤 파일이 바뀌면 다시 확인하며, 영구 삭제로 전환하지 않습니다.
- **설정 › 고급 › 실행 기록**은 모든 계정의 수동·자동 저장 결과를 최근 1,000건까지 짧은 목록으로 보여 줍니다. 계정 선택 없이 계정 이름이 각 줄에 표시되며, 이전 버전 기록은 현재 계정의 것만 함께 나옵니다. 삭제 이력·통계 화면은 사용 빈도가 낮아 없앴으며, 기존 기록 데이터는 그대로 남아 있습니다.
- **저장 못 한 미디어**는 갤러리처럼 창 전체에서 사진 타일로 봅니다. 갤러리 위쪽의 **저장 못 한 미디어** 버튼, **설정 › 고급 › 저장 못 한 미디어**, 저장 화면의 안내가 모두 이 화면을 열고, **← 갤러리**나 Esc로 돌아옵니다. 타일을 눌러 고르면 위의 버튼이 고른 것에만 적용되고, 고르지 않으면 목록 전체에 적용됩니다. 갤러리처럼 Shift+클릭으로 범위를, 끌어서 사각형 안을 고르며(Ctrl+A는 불러온 것 전부, Esc는 선택 해제), 아래로 내리면 다음 것을 이어서 불러옵니다. 목록은 세 가지입니다. ‘저장하지 못함’은 저장에 실패했거나 크기 제한으로 건너뛴 사진·영상·GIF를 이유와 함께 보여 줍니다. ‘없어진 파일’은 저장했지만 폴더에 파일이 없어 갤러리에 ‘파일 없음’ 칸으로 나오는 미디어로, **다시 받기**로 지금 다시 받거나 **갤러리에서 빼기**로 갤러리에서 감추고 다시 받지 않게 합니다(기록은 지우지 않으며 ‘직접 제외’에서 되돌립니다). 실패·용량 초과 목록은 계정·저장 폴더별로 최대 500건이며, **목록에서 지우기**는 그 표시만 지웁니다. ‘직접 제외’ 탭은 카탈로그에 남은 제외 기록입니다. 저장 확인의 ‘저장 안 함’과, 지울 때 다시 받지 않기로 한 항목이 나오며 실패로 세지 않습니다. **제외 해제**는 다음 저장에서 다시 받게 하고, **다시 받기**는 지금 받습니다. 목록을 지워도 제외 기록은 빠지지 않고, 저장 폴더를 옮겨도 그 폴더의 카탈로그에서 다시 볼 수 있습니다. 이미 저장했거나 중복이라 건너뛴 미디어는 목록에 쌓이지 않고, 나중에 저장되면 실패 목록에서 자동으로 사라집니다. 미리보기는 이 PC에 남아 있는 것만 보여 주며, 저장하지 못한 항목과 직접 제외한 항목의 빈 미리보기는 전체 목록 다시 확인으로 저장할 때 작은 그림 한 장씩 받아 채웁니다.
- 휴지통의 파일 복원은 Windows 휴지통에서 직접 수행합니다. 확장 스토어 배포와 자동 설치는 아직 제공하지 않습니다.
