# LuvBox 브라우저 연결 확장 개인정보 처리 안내

LuvBox 브라우저 연결 확장은 브라우저에 로그인된 X 계정을 같은 PC의 LuvBox 앱에 연결할 때만 사용합니다.

## 확인하는 정보와 시점

사용자가 LuvBox에서 브라우저 연결을 시작하고, 확장 화면에서 연결 코드 8자리를 확인해 체크하거나 **계정 다시 확인**을 누를 때만 현재 브라우저 프로필의 X 로그인 상태와 계정 정보(아이디·표시 이름)를 확인합니다. 본인 계정을 확인하기 위해 X 탭이 잠깐 열렸다 닫힙니다.

X 비밀번호를 입력받거나 읽지 않으며, 다른 사이트의 정보나 방문 기록, 결제 정보, 연락처, 메시지는 수집하지 않습니다.

## 사용 목적과 전달

확인한 계정과 로그인 정보는 사용자가 브라우저에서 **@아이디 연결**을 누르고 LuvBox 앱에서 **이 계정 연결 승인**을 눌렀을 때만 계정 연결에 사용합니다.

모든 정보는 같은 PC에서 실행 중인 LuvBox 앱으로만 안전하게 암호화해 전달하며, 외부 서버나 개발자에게 보내거나 광고·분석에 사용하지 않습니다. 연결 뒤 X에서 좋아요 목록과 사진·영상을 저장하는 동작은 사용자가 LuvBox 앱에서 직접 실행할 때만 이뤄집니다.

## 보관과 연결 해제

확장은 연결이 진행되는 짧은 시간(최대 3분) 동안만 연결 상태를 임시로 유지하며, 연결이 끝나거나 연결 탭을 닫으면 즉시 비웁니다.

승인한 로그인 정보는 이 PC의 현재 Windows 사용자 계정에만 암호화해 보관합니다. 확장을 브라우저에서 지워도 이미 저장한 계정이 자동으로 지워지지는 않으므로, 연결을 끊으려면 앱의 **현재 계정 연결 해제**를 눌러 주세요. 저장한 사진·영상과 기록은 사용자가 직접 지울 때까지 유지됩니다.
