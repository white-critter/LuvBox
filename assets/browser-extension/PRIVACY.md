# LuvBox 브라우저 연결 확장 개인정보 처리 안내

게시 전 초안 · 2026-10-24

이 문서는 현재 확장과 Windows용 LuvBox의 연결 동작을 설명합니다. 발행자는 스토어 제출 전에 실제 발행자 이름, 공개 지원 연락처와 이 문서의 공개 웹 주소를 확정해야 합니다. 현재 문서만으로 스토어 등록이나 심사가 완료되지는 않습니다.

## 처리하는 정보와 시점

사용자가 LuvBox에서 브라우저 연결을 시작하고, 확장 화면에서 같은 연결 코드임을 확인한 뒤 **현재 X 계정 확인**을 누르면 확장은 현재 브라우저 프로필의 X 로그인 쿠키 `auth_token`과 계정 확인용 `twid`를 읽습니다. `twid`에서 계정 ID를 확인하고, 잠시 연 `https://x.com/home` 탭에서 본인의 사용자 이름과 표시 이름을 확인합니다. 계정 확인용 탭은 확인 후 닫습니다.

확장은 비밀번호 입력을 받거나 읽지 않습니다. 다른 사이트의 쿠키, 전체 방문 기록, 결제 정보, 연락처나 메시지를 수집하는 기능은 없습니다. 스토어 등록 화면, 지원 문의나 후기에서 X 비밀번호, 로그인 쿠키, 토큰 또는 연결 페이지 주소를 보내도록 요청하지 않습니다.

## 사용 목적과 전송

확장의 목적은 사용자가 선택한 X 로그인을 같은 컴퓨터의 LuvBox에 연결하는 것입니다. 코드와 계정을 확인한 사용자가 확장의 **@아이디 연결**을 눌러야 로그인 쿠키, 계정 ID, 사용자 이름과 표시 이름을 앱에 전송합니다. 앱에서도 표시된 계정을 확인하고 **이 계정 연결 승인**을 눌러야 연결을 저장합니다.

전송 대상은 같은 컴퓨터에서 대기 중인 LuvBox의 `127.0.0.1` 임시 포트입니다. 전송 주소는 HTTP 루프백 주소이며, 쿠키와 계정 정보를 포함하는 본문은 AES-GCM으로 암호화하고 별도로 유도한 HMAC-SHA-256으로 인증합니다. 연결마다 생성한 일회성 비밀값에서 키를 유도합니다. 이 설명은 현재 구현을 기술하며 스토어 심사 적합성을 보증하지 않습니다.

확장에는 개발자가 운영하는 원격 수집 서버, 분석 도구나 광고 추적 기능이 없습니다. 계정 정보나 로그인 쿠키를 개발자 또는 광고업체에 보내거나 판매하는 기능도 없습니다. 계정 확인을 위해 열리는 X 탭은 X와 통신하며 X의 자체 데이터 처리는 X의 정책에 따릅니다. 연결 뒤 LuvBox가 수행하는 X 요청과 다운로드는 사용자가 앱에서 요청하는 별도 동작입니다.

## 보관과 삭제

확장은 연결 대기 상태와 확인한 세션을 메모리에만 보관하고 확장 저장소에 기록하지 않습니다. 연결 대기는 최대 3분이며, 전송 완료, 연결 탭 닫기 또는 확장 백그라운드 종료 시 관련 대기 상태가 해제됩니다. 취소하려면 앱에서 **연결 취소**를 누르거나 연결 탭을 닫으세요.

앱이 승인한 로그인 쿠키와 계정 레코드는 해당 Windows 사용자 범위의 DPAPI로 암호화해 로컬에 저장합니다. 앱 설정이나 저장한 파일·기록에 사용자 이름이 남을 수 있습니다. 확장을 제거해도 이미 앱에 저장한 연결이 자동으로 삭제되지는 않습니다. 앱의 **현재 계정 연결 해제**로 해당 계정의 저장된 로그인을 제거하세요. 저장된 여러 계정을 모두 제거하려면 각 계정을 선택해 연결을 해제해야 합니다. 앱에서 내려받은 파일과 기록은 별도로 삭제해야 합니다.

## 문의와 게시 전 확인

발행자가 확정한 Chrome Web Store의 공개 지원 연락처로 문의하세요. 민감한 로그인 값은 문의 내용에 포함하지 마세요. 공개 지원 연락처가 정해지기 전에는 이 초안을 최종 개인정보처리방침으로 게시하지 않습니다.

Chrome은 로컬에서만 처리하는 정보도 공개하도록 안내합니다. 발행자는 실제 동작, 공개 정책과 개발자 대시보드의 신고 내용을 일치시켜야 합니다. [Chrome 사용자 데이터 FAQ](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq), [개인정보 신고 항목 안내](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)를 참고하세요.
