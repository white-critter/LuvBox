# 브라우저 연결용 확장

LuvBox는 선택한 **Chrome·Edge·Firefox**의 X 계정을 연결합니다. 앱의 **X 연결**에서 쓰는 브라우저를 고르고, X에 로그인한 일반 브라우저 프로필에서 진행하세요.

이미 확장을 설치했다면 **X 계정 연결** 또는 **다시 연결**을 바로 누르세요. 연결이 이어지지 않으면 다른 프로필을 쓰고 있거나 확장이 꺼져 있는지 확인해 주세요.

## Chrome · Edge 처음 설치

1. **X 연결**에서 **확장 설치·연결 도움말**을 펼치고 **확장 관리 주소 복사·브라우저 열기**를 누릅니다. 브라우저 주소창에 복사된 주소(`chrome://extensions` 또는 `edge://extensions`)를 붙여 넣어 확장 관리 화면을 엽니다.
2. 오른쪽 위의 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드**를 누릅니다.
3. 폴더 선택 창이 열리면(보통 ‘문서’가 먼저 열립니다) 연결창의 **폴더 경로 복사**를 누른 뒤, 폴더 선택 창의 주소창에 붙여 넣고 Enter를 누릅니다. `manifest.json`이 보이는 폴더가 열리면 그 폴더를 선택하세요. (압축 파일을 그대로 고르면 설치되지 않습니다.)
4. 연결창의 **X 열기**를 눌러 확장을 설치한 같은 프로필에서 X에 로그인한 뒤, 앱에서 **X 계정 연결**을 누릅니다.

## Firefox 처음 설치

1. **X 연결**에서 **Mozilla Firefox**를 고르고 **확장 설치·연결 도움말**을 펼칩니다.
2. **확장 관리 주소 복사·브라우저 열기**를 누르고 Firefox 주소창에 복사된 `about:debugging#/runtime/this-firefox`를 붙여 넣습니다.
3. **임시 부가 기능 로드**를 누른 뒤, 연결창에서 **폴더 경로 복사**로 이동한 폴더 안의 **manifest.json**을 선택합니다.
4. 같은 프로필에서 X에 로그인하고 앱에서 **X 계정 연결**을 누릅니다.

Firefox의 임시 확장은 브라우저를 완전히 닫았다가 다시 열면 사라지므로, 다음에 새로 연결할 때 다시 불러와 주세요. 이미 연결해 둔 계정은 그대로 유지됩니다.

## 연결 승인과 다시 시도

1. 앱과 브라우저 화면의 **연결 코드 8자리**가 같은지 확인하고 체크합니다. 체크하면 현재 X 계정을 확인하며, 이 과정에서 X 탭이 잠깐 열렸다 닫힙니다.
2. 표시된 계정이 본인 것인지 확인한 뒤 브라우저에서 **@아이디 연결**을 누릅니다.
3. LuvBox 앱으로 돌아와 같은 계정인지 확인하고 **이 계정 연결 승인**까지 누르면 연결이 저장됩니다.

브라우저에서 X에 새로 로그인하거나 계정을 바꿨다면 확장 화면의 **계정 다시 확인**을 누르세요. 브라우저나 프로필을 바꾸려면 앱에서 **연결 취소** 후 다시 연결하세요.

## 앱 업데이트 후 확장 새로고침

LuvBox를 업데이트한 뒤 새 연결 화면을 쓰려면 앱의 **X 연결** 창을 한 번 열고, 브라우저 확장 관리 화면에서 LuvBox 확장의 **새로고침**을 누르세요. Firefox는 **임시 부가 기능 로드**로 다시 불러옵니다.

이미 저장한 계정은 확장을 새로고침하지 않아도 그대로 사용할 수 있습니다.

## 알아 둘 점

- 승인한 X 로그인 정보만 이 PC의 앱에 전달해 암호화 보관합니다. 로그인 정보나 연결 화면 주소는 다른 사람에게 보내지 마세요.
- 저장한 연결은 앱의 **현재 계정 연결 해제**로, 확장은 브라우저 확장 관리에서 지울 수 있습니다.
- Safari, 시크릿·비공개 창, Firefox 컨테이너 탭, 외부 확장이 제한된 환경에서는 확장 연결을 쓸 수 없습니다. 이럴 때는 연결 창의 **고급 연결 · 토큰 입력**을 이용해 주세요.
