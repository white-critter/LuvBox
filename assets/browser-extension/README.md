# 기본 브라우저의 X 로그인 연결

LuvBox의 **기본 브라우저 연결**은 현재 브라우저에 로그인한 X 계정을 사용합니다. 처음에는 이 폴더의 연결 확장을 직접 설치해야 합니다. 브라우저의 로그인 정보를 앱이 몰래 읽거나 확장을 자동 설치하지 않습니다.

## Chrome · Edge · Chromium

1. X에 로그인한 브라우저의 **일반 창**에서 확장 관리 화면을 엽니다. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`입니다.
2. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드**를 선택합니다.
3. 이 폴더 안의 **chromium** 폴더를 선택합니다.
4. LuvBox로 돌아와 **기본 브라우저 연결**을 다시 누릅니다.

Brave 등 Chromium 기반 브라우저도 같은 형식의 확장을 사용하지만 모든 제품에서 확인하지는 못했습니다. 기본 브라우저가 여러 프로필을 사용한다면 확장을 설치하고 X에 로그인한 프로필에서 연결 페이지를 여세요.

## Firefox 128 이상

1. 일반 창에서 `about:debugging#/runtime/this-firefox`를 엽니다.
2. **임시 부가 기능 로드**를 누르고 이 폴더 안의 **firefox/manifest.json**을 선택합니다.
3. LuvBox에서 **기본 브라우저 연결**을 다시 누릅니다.

이 방식의 Firefox 확장은 브라우저를 다시 시작하면 제거됩니다. 다음 연결 전에 다시 설치해야 합니다. 영구 설치를 위한 Mozilla 서명·스토어 배포는 아직 제공하지 않습니다. 이미 LuvBox에 연결해 저장한 계정은 확장이 제거돼도 유지됩니다.

## 연결 승인

1. LuvBox와 브라우저 확장에 표시된 **연결 코드 8자리**가 같은지 확인하고 체크합니다.
2. **현재 X 계정 확인**을 누릅니다. 기존 로그인으로 X 탭을 잠시 열어 본인 계정을 확인한 뒤 닫습니다. 아이디를 입력할 필요가 없습니다.
3. 표시된 **@아이디 연결**을 누릅니다. 앱으로 돌아와 최종 연결 결과를 확인합니다.

계정을 바꾸려면 이 브라우저의 x.com에서 계정을 전환한 뒤 다시 확인하세요. 연결 대기는 기본 3분이며 시간이 지나면 앱에서 다시 시작하면 됩니다. 설치할 때도 연결 대기 시간이 지날 수 있으므로 설치 후에는 새로 연결하세요.

확장은 x.com의 쿠키 접근과 이 컴퓨터의 연결 페이지 접근만 요청합니다. X 비밀번호와 다른 사이트의 쿠키는 읽지 않습니다. X 로그인 쿠키와 계정 정보는 승인한 연결 때 암호화해 이 컴퓨터의 LuvBox로 전달하고, 앱은 Windows 사용자별 암호화 저장소에 저장합니다. 확장은 로그인 쿠키를 디스크에 저장하지 않습니다. 연결을 원하지 않으면 탭을 닫거나 앱에서 취소하세요. 앱에서 계정 연결을 해제할 수 있으며 확장도 브라우저 확장 관리 화면에서 제거할 수 있습니다.

Safari, 비공개 창, Firefox 컨테이너, 관리 정책으로 외부 확장을 막은 브라우저는 이 방식으로 연결할 수 없습니다. 이 경우 앱의 별도 로그인 창이나 토큰 입력을 선택할 수 있습니다. 브라우저·회사 정책을 변경하거나 기존 로그인 프로필의 잠금을 해제하지 마세요.

실제 사용자 X 계정과 Windows 브라우저로 설치·로그인 전 과정을 검증하지는 못했습니다. 개발 환경의 Chromium은 관리 정책으로 개발 확장 설치가 차단되어, 실제 확장 통합 검사는 차단 사유와 함께 건너뜁니다. 서버 경계와 암호화·확장 동작은 합성 계정으로 검사합니다.
