# 브라우저 연결용 확장

LuvBox의 로그인 방법은 **브라우저 연결**과 **토큰 입력** 두 가지입니다. 브라우저 연결 탭의 설정 버튼으로 확장 설치를 준비할 수 있습니다. 확장 설치와 계정 연결 승인은 사용자가 직접 완료합니다.

## Chrome · Edge · Chromium

1. LuvBox의 **브라우저 연결 → 확장 관리 열기**를 누릅니다. 브라우저가 열리고 관리 화면 주소가 복사됩니다. 브라우저는 이 주소를 명령줄로 열지 않으므로 주소창에 붙여 넣으세요. 직접 입력하려면 Chrome은 `chrome://extensions`, Edge는 `edge://extensions`입니다.
2. 관리 화면의 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드**를 선택합니다.
3. 앱의 **폴더 경로 복사**를 눌러 폴더 선택 창에 붙여 넣거나, **폴더 열기**로 위치를 확인하세요. 앱은 확장을 `%LOCALAPPDATA%\LuvBox\browser-extension\chromium`에 복사해 이 폴더를 안내합니다. 앱 버전을 바꾸거나 이전 버전 폴더를 지워도 이 폴더는 유지됩니다. 1.1.5 이하에서 앱 폴더의 확장을 불러왔다면 한 번 이 폴더로 다시 불러와 주세요.
4. **X 열기**를 눌러 확장을 설치한 프로필에서 로그인합니다. 여러 프로필을 쓴다면 프로필을 직접 확인하세요.
5. 준비가 끝나면 **브라우저에서 연결**을 누르고 아래의 연결 승인을 진행합니다. 설정 버튼만 눌러서는 계정을 연결하지 않습니다.

기본 브라우저가 Chrome·Edge가 아니면 **확장 관리 열기**가 직접 여는 방법을 안내합니다. Brave 등 Chromium 기반 브라우저도 같은 형식의 확장을 사용하지만 모든 제품에서 확인하지는 못했습니다. 확장을 설치하고 X에 로그인한 프로필에서 연결 페이지를 여세요. 확장 자동 설치나 스토어 배포는 제공하지 않습니다.

## Firefox 128 이상

1. 일반 창에서 `about:debugging#/runtime/this-firefox`를 엽니다.
2. **임시 부가 기능 로드**를 누르고 이 폴더 안의 **firefox/manifest.json**을 선택합니다.
3. x.com에 로그인한 뒤 LuvBox의 **브라우저 연결 → 브라우저에서 연결**을 누릅니다.

이 방식의 Firefox 확장은 브라우저를 다시 시작하면 제거됩니다. 다음 연결 전에 다시 설치해야 합니다. 영구 설치를 위한 Mozilla 서명·스토어 배포는 아직 제공하지 않습니다. 이미 LuvBox에 연결해 저장한 계정은 확장이 제거돼도 유지됩니다.

## 연결 승인

1. 앱과 확장 페이지의 **연결 코드 8자리**가 같은지 확인하고 체크합니다.
2. **현재 X 계정 확인**을 누르고 표시된 계정이 본인 것인지 확인합니다. 확인 중 X 탭이 잠시 열렸다 닫힙니다.
3. 브라우저에서 **@아이디 연결**을 누릅니다.
4. 앱으로 돌아와 같은 계정인지 확인하고 **이 계정 연결 승인**을 누릅니다.

계정을 바꾸려면 x.com에서 전환한 뒤 다시 확인하세요. 연결 대기 3분이 지나면 앱에서 다시 시작하세요.

승인한 X 로그인 쿠키와 계정 정보만 이 컴퓨터의 앱에 전달하고 Windows 사용자별 암호화 저장소에 저장합니다. **토큰·쿠키·연결 페이지 주소는 다른 사람에게 보내지 마세요.** 연결을 원하지 않으면 앱에서 **연결 취소**, 저장한 연결은 **연결 해제**를 누르세요. 확장은 브라우저 확장 관리에서 제거할 수 있습니다.

Safari, 비공개 창, Firefox 컨테이너, 외부 확장이 차단된 브라우저는 지원하지 않습니다. 대신 앱의 **토큰 입력**을 사용하세요. 브라우저·회사 보안 정책을 우회하지 마세요.
