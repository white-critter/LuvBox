# 브라우저 연결용 확장

LuvBox 1.1.9는 선택한 **Chrome·Edge·Firefox**의 X 계정을 연결합니다. 앱의 **X 연결**에서 브라우저를 선택하세요. 설치 안내·X 열기·실제 연결에 같은 브라우저를 사용하며 선택을 기억합니다. 브라우저가 여는 일반 프로필을 확인하세요. 앱은 다른 프로필을 추정하거나 강제로 바꾸지 않습니다.

이미 확장을 설치했다면 **X 계정 연결** 또는 **다시 연결**을 바로 누릅니다. 처음 설치 도움말은 접혀 있습니다. 연결 시작 후 약 8초간 확장 응답이 없으면 도움말을 펼칩니다. 응답 없음은 미설치 확정이 아닙니다. 다른 프로필, 꺼진 확장, 이전 확장 버전, 브라우저 정책도 확인하세요.

## Chrome · Edge 처음 설치

1. **처음 연결하거나 확장 응답이 없나요?**를 펼치고 **확장 관리 주소 복사·브라우저 열기**를 누릅니다. 선택한 브라우저의 주소창에 복사된 주소를 붙여 넣으세요. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`입니다. 앱이 관리 화면을 직접 열거나 확장을 자동 설치한 것으로 표시하지 않습니다.
2. 관리 화면의 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드**를 선택합니다.
3. 연결창의 **폴더 경로 복사**를 누르고 폴더 선택 창의 **주소창**에 붙여 넣은 뒤 Enter를 누릅니다. 선택 창은 보통 ‘문서’에서 열립니다. 문서 폴더 자체를 고르면 매니페스트 오류가 납니다. `manifest.json`이 보이는 폴더만 선택하세요. ZIP을 그대로 고르거나 풀지 않은 채 선택하면 설치되지 않습니다.
4. **X 열기**를 눌러 같은 브라우저의 확장을 설치한 일반 프로필에서 로그인합니다. 앱에서 **X 계정 연결**을 누르고 아래의 연결 승인을 진행합니다.

앱은 확장을 `%LOCALAPPDATA%\LuvBox\browser-extension\chromium`에 복사합니다. 앱 버전을 바꾸거나 이전 버전 폴더를 지워도 이 폴더는 유지됩니다. 1.1.5 이하에서 앱 폴더의 확장을 불러왔다면 한 번 이 경로로 다시 불러와 주세요. Brave 등 다른 Chromium 제품은 앱의 브라우저 선택 대상으로 제공하지 않습니다.

## Firefox 128 이상 처음 설치

1. 앱의 **X 연결**에서 **Mozilla Firefox**를 선택하고 설치 도움말을 펼칩니다.
2. **확장 관리 주소 복사·브라우저 열기**를 누르고 Firefox 주소창에 복사된 `about:debugging#/runtime/this-firefox`를 붙여 넣습니다.
3. **임시 부가 기능 로드**를 누르고 연결창에 표시된 `%LOCALAPPDATA%\LuvBox\browser-extension\firefox` 폴더의 **manifest.json**을 선택합니다. Chrome용 폴더를 고르지 마세요.
4. 같은 일반 프로필에서 X에 로그인하고 앱의 **X 계정 연결**을 누릅니다.

Firefox 임시 확장은 브라우저를 다시 시작하면 제거되므로 다음 연결 전에 다시 불러와야 합니다. 이미 앱에 저장한 계정은 확장이 제거돼도 유지됩니다. Mozilla 서명·스토어 배포는 아직 제공하지 않습니다.

## 연결 승인과 다시 시도

1. 앱과 확장 페이지의 **연결 코드 8자리**가 같은지 확인하고 체크합니다. 체크하면 현재 X 계정을 자동 확인합니다. 확인 중 X 탭이 잠시 열렸다 닫힙니다.
2. 표시된 계정이 본인 것인지 확인한 뒤 브라우저에서 **@아이디 연결**을 누릅니다.
3. 앱으로 돌아와 같은 계정인지 확인하고 **이 계정 연결 승인**을 누릅니다. 브라우저의 전달 성공과 앱의 암호화 저장 완료는 별도입니다.

X 로그인·추가 인증이 필요하면 선택한 브라우저에서 완료한 뒤 확장의 **계정 다시 확인**을 누르세요. 계정을 바꿨거나 계정을 읽지 못했을 때도 같은 버튼으로 재확인합니다. 앱은 확장 응답·계정 확인·브라우저 승인·앱 승인을 구분해 표시하며 브라우저 연결과 앱 최종 승인은 각각 최대 180초 대기합니다.

설치나 프로필 선택을 고쳤다면 앱에서 **연결 취소** 후 다시 연결하세요. 열린 연결 탭의 주소는 일회성이므로 새로고침하거나 다른 사람에게 보내지 마세요. 저장 중 `다시 연결 필요`가 나오더라도 기존 연결 정보·미디어·기록을 자동으로 지우지 않습니다. 통신 장애나 요청 제한은 로그인 만료와 구분합니다.

## 앱 업데이트 후 확장 갱신

새 단계 표시를 쓰려면 앱의 **X 연결**을 한 번 열어 확장 파일을 갱신한 다음 브라우저 확장 관리에서 LuvBox 확장의 **새로고침**을 누르세요. 현재 확장 버전은 **1.1.0**이며 앱 버전과 별도입니다. Firefox는 갱신된 `firefox/manifest.json`을 다시 불러옵니다.

이전 **1.0.0** 확장도 기존 최종 계정 전달 형식으로 연결할 수 있지만 앱의 중간 단계 표시는 지원하지 않습니다. 기존에 저장한 계정은 확장을 갱신하기 위해 다시 연결할 필요가 없습니다.

승인한 X 로그인 쿠키와 계정 정보만 이 컴퓨터의 앱에 전달하고 Windows 사용자별 암호화 저장소에 보관합니다. **토큰·쿠키·연결 페이지 주소는 다른 사람에게 보내지 마세요.** 저장한 연결은 앱의 **현재 계정 연결 해제**로, 확장은 브라우저 확장 관리에서 제거할 수 있습니다.

Safari, 비공개 창, Firefox 컨테이너, 외부 확장이 차단된 환경은 지원하지 않습니다. 대체 수단은 앱의 **고급 연결 · 토큰 입력**입니다. 토큰 보관만으로 실제 X 인증이 확인되지는 않습니다. 확장 자동 설치·스토어 배포는 아직 제공하지 않으며 회사·브라우저 보안 정책을 우회하지 않습니다.
