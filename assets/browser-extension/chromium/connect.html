2연결할 X 계정

코드를 확인하면 이 브라우저의 X 계정을 바로 확인합니다. 확인하는 동안 X 탭이 잠시 열렸다 닫힙니다.

3연결 승인

승인하면 이 계정의 X 로그인 정보와 계정 정보가 암호화되어 이 컴퓨터의 LuvBox에만 전달됩니다. 비밀번호는 전달되지 않으며, 앱에서 한 번 더 승인해야 저장됩니다.

다른 X 계정을 연결하려면 이 브라우저의 x.com에서 먼저 계정을 바꾼 뒤 ‘계정 다시 확인’을 누르세요. 시크릿·비공개 창과 Firefox 컨테이너는 지원하지 않습니다. 앱에서 취소하거나 이 탭을 닫으면 연결이 중단됩니다.
